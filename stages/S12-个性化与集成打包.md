## 1. 目标

补齐学段自适应机制；内容安全终审；四学段内容补齐；**集成回归 + 最终打包**。

## 2. 任务清单

### 2.1 学段自适应（**v2 形态：显式为主 + 推断为辅**）

- [ ] **显式选择为权威**（前端按钮，赛题硬要求）；变更写入 `grade_history(source=explicit)`
- [ ] **信号提取**（四类）：词汇复杂度 / 问题深度 / 答题表现 / 元认知表达
      - [ ] 第一层：每轮同步规则检测，写 `grade_signals` 表（**不调额外 LLM**）
      - [ ] 第二层：第 3 轮（不足则第 5 轮）触发轻量 LLM 判定 → `{suggestedAdjustment, confidence}`
- [ ] **规则引擎决策**（最终决策权在此，不在 LLM）：
      - [ ] 置信度 **< 0.6 不调整**
      - [ ] **方向一致性**：连续 3 个信号同方向
      - [ ] **冷却期**：调整后 5 轮内不重复调整
      - [ ] **★ 人工纠偏出口**：学生可随时显式重选，重选后冷却期重置
- [ ] **推断只写「建议」，不直接改** —— UI 弹建议条，**由学生确认**后写 `grade_history(source=confirmed)`
- [ ] 学段变化轨迹可在家长/教师报告中展示

> **为什么不做纯自动推断**：赛题原文是「**学生可选择所在学段**」——
> 「可选择」是明确要求；且演示脚本含「同一问题四学段对比」，去掉按钮该动作不成立。

### 2.2 内容安全

- [ ] 输入侧：敏感词 / 越狱意图轻量检查
- [ ] 生成侧：**流式输出 + 生成结束后整段终审**（**不阻塞首 token**）
- [ ] 违规处置：**撤回该条消息**，替换 `blocked.safeText`，**给过渡提示**
- [ ] 双重过滤：敏感词库（JSON 可扩展）+ LLM 自审 prompt

### 2.3 内容补齐

- [ ] 四学段内容补齐，**全量抽检**（小学高/初中做深作展示，另两学段保主线）

### 2.4 集成回归 + 打包

- [ ] 全链路走查（四交互 + 四学段）
- [ ] **每加一个原生/数据依赖就重跑一次打包冒烟**，别攒到最后
- [ ] `electron-builder` 最终整包 → `win-unpacked/` 双击实测
- [ ] **★ Pi 的 `esbuild` 在整包里可加载**（v2 关键项）

## 3. 验收标准（DoD / 关卡 E）

- [ ] 四交互（对话/动画/编程/练习）在四学段下均可演示
- [ ] **学段建议条可演示**：达阈值时弹出，学生确认后写 `grade_history`
- [ ] **学生可随时显式改回**（人工纠偏出口可用）
- [ ] 违规内容能撤回并替换，**体验不突兀**
- [ ] 打包产物双击可运行，**无孤儿进程**，冷启动可接受
- [ ] **★ 打包产物里 Pi 正常加载**（`esbuild` 问题已解或已切 RPC 模式）
- [ ] 安装包体积在可接受范围（报告主动说明本地化 + 随包模型的代价）

## 4. 陷阱

| # | 陷阱 | 说明 |
| --- | --- | --- |
| 1 | **新增依赖后忘重打包** | 每加一个依赖就重跑一次冒烟。 |
| 2 | 安全审核拖慢响应 | **终审在流结束之后做**，不阻塞首 token。 |
| 3 | 违规撤回体验突兀 | 要给过渡提示（「刚才的内容不适宜，已为你换成…」）。 |
| 4 | 四学段内容不均 | 小学高/初中做深作展示，**全量抽检**。 |
| 5 | **★ Pi 的 `esbuild`** | asarUnpack + 按架构分发 + 签名。见执行文档风险 #15。 |
| 6 | **学段误判锁死体验** | 必须有**人工纠偏出口**（原提案缺这个出口）。 |
| 7 | 安装包过大 | `--onedir` + `--exclude-module`；报告**主动说明**。 |
