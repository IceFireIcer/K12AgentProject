## 3. 关键命令

### 3.1 初始化与依赖

```bash
cd server
uv python pin 3.12                                  # → .python-version（必须提交）
uv init --bare --python 3.12 .
uv add fastapi "uvicorn[standard]" pydantic langgraph \
       langgraph-checkpoint-sqlite langchain-openai \
       fastembed sqlite-vec numpy
uv add --dev pyinstaller
uv run python -c "import sys; print(sys.version)"   # 期望 3.12.x
```

> ⚠️ **全程只用 `uv run`，禁止裸 `python` / `py`**。本机 `py` 默认项指向已删除的 `D:\Code\PythonEvm`，裸命令报 `0x80070003`（见执行文档风险 #2）。

### 3.2 下载嵌入模型（离线可用）

```bash
cd server
uv run python scripts/download_models.py
```

`scripts/download_models.py` 要点：

```python
from pathlib import Path
from fastembed import TextEmbedding

CACHE = Path(__file__).resolve().parent.parent / "resources" / "models" / "fastembed"
CACHE.mkdir(parents=True, exist_ok=True)

# 触发下载 + 落盘到指定目录
model = TextEmbedding(model_name="BAAI/bge-small-zh-v1.5", cache_dir=str(CACHE))
vec = next(iter(model.embed(["测试"])))
print("维度 =", len(vec))   # 必须为 512
```

> **为什么指定 cache_dir**：默认落在 `~/.cache/fastembed`，PyInstaller 打包时收不到。必须在 `resources/models/` 里留一份，运行时通过 `cache_dir` 显式指向（打包后路径由 sidecar 从 `--data-dir`/`sys._MEIPASS` 推导）。

## 6. 陷阱与注意

| # | 陷阱 | 说明 |
| --- | --- | --- |
| 1 | 裸 `python` 报 0x80070003 | 本机 py 启动器默认项指向不存在的目录。**不要去改注册表**，用 uv 锁解释器绕开。 |
| 2 | 模型落默认缓存导致打包丢失 | 必须显式 `cache_dir=` 到 `server/resources/models/`。 |
| 3 | sqlite-vec 需要 `enable_load_extension` | 加载三连：`enable_load_extension(True)` → `sqlite_vec.load(conn)` → `enable_load_extension(False)`。 |
| 4 | 中文编码 | 本机全局有 `PYTHONUTF8=1`，利好；但**打包后的子进程不继承**，须在 spawn 时显式传（S01 处理）。 |
| 5 | fastembed 首次会下 ONNX Runtime | 属于 fastembed 依赖，装包时一并拉取，注意体积。 |
| 6 | 维度写死风险 | 512 这个数字要**写进配置常量**（S06 用），不要散落硬编码——将来升级 `bge-base-zh-v1.5`(768) 要重建索引。 |
