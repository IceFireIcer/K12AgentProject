## 3. 关键约束（**后续所有 Stage 都适用**）

- **全程只用 `uv run`，禁止裸 `python` / `py`**：本机 `py` 默认项指向已删除的 `D:\Code\PythonEvm`，
  裸命令报 `0x80070003`。**不要改注册表**，用 uv 锁解释器绕开。
- **模型必须落 `server/resources/models/fastembed/`**（显式 `cache_dir=`）：
  落默认用户缓存会导致 PyInstaller 收不到。
- **嵌入维度 512 要写成配置常量**，不散落硬编码（升级模型要同步改 `vec0` 维度并重建索引）。

## 4. 陷阱

| # | 陷阱 | 说明 |
| --- | --- | --- |
| 1 | 裸 `python` 报 0x80070003 | 用 uv 锁解释器绕开，**不动注册表**。 |
| 2 | `.gitignore` 模式锚定 | `resources/models/` **挡不住** `server/resources/models/`，须写 `**/resources/models/`（90MB 模型险些入库）。 |
| 3 | 模型落默认缓存 → 打包丢失 | 必须显式 `cache_dir=` 到 `server/resources/`。 |
| 4 | HF 缓存 symlink | 本机不支持符号链接 → 落为**实体文件**，**反而更好**（打包不会拿到断裂软链）。 |
| 5 | sqlite-vec 加载三连 | `enable_load_extension(True)` → `sqlite_vec.load(conn)` → `enable_load_extension(False)`。 |
