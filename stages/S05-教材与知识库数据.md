## 1. 目标

产出**人工审核过的四学段教材**（Markdown + 元数据），这是 20% 教育适配性的内容基础。

## 2. 任务清单

- [ ] 目录：`server/knowledge/{primary-low,primary-high,junior,senior}/`
- [ ] 每学段 **8–12 个知识点**；优先做深 **小学高年级 + 初中**（报告主展示）
- [ ] 元数据 `manifest.json`：`grade_level` / `chapter_title` / `section_title` /
      `knowledge_point` / `content_type` / **依赖关系（`from`/`to`）**
- [ ] **AI 批量生成 + 人工只定骨架与抽检**（内容编写是拖垮全盘的头号风险）
- [ ] 学段语气按执行文档 10.5 的矩阵差异化（童趣比喻 / 严谨逻辑）

## 3. 四学段知识主线（据执行文档 10.5）

| 学段 | 主线 |
| --- | --- |
| 小学低年级 | 身边的 AI、机器怎么看/听、AI 有礼貌吗 |
| 小学高年级 | 语音识别、图像分类、数据/训练/预测、AI 伦理与安全 |
| 初中 | 数据与特征、决策树、神经网络基础、Python 数据处理、模型训练与评估入门 |
| 高中 | 机器学习全流程、损失函数与梯度下降直觉、线性回归/分类/KNN、NumPy 实践、过拟合与评估、项目式（手写数字识别） |

## 4. 验收标准（DoD）

- [ ] 四学段均有内容，**每学段至少 8–12 个知识点**
- [ ] 每个 chunk 的 `grade_level` / `knowledge_point` 标注完整，**无空字段**
- [ ] `manifest.json` 依赖关系的 `from`/`to` **都能在知识点表中找到（无悬空引用）**
- [ ] **抽检通过**：随机抽 20% 人工核对，事实性错误已修正（**留记录**）
- [ ] 小学低年级文本不含超纲术语；高中文本不出现「小朋友」这类错位语气

## 5. 陷阱

**完整清单见 `docs/业务陷阱清单.md` 第 1 节**。要点：

| # | 陷阱 | 说明 |
| --- | --- | --- |
| 1 | **内容编写耗时失控** | **头号风险**。必须 AI 生成 + 人工只做骨架与抽检。 |
| 2 | 元数据字段随手改 | 必须与执行文档 8.3 的 DDL 严格对齐，否则建索引报错。 |

| 4 | 学段错位 | 跨学段复用要**改写**而非直接搬运。 |
