## 1. 目标

产出一份**结构化的 Markdown 教材 + 元数据**，覆盖四学段，能被 S06 的分块脚本吃进去。内容策略沿用研判文档结论：**人工定骨架 + AI 填血肉 + 人工抽检**。

**深度分级（关键）**：小学高年级、初中 **做深**（报告主展示）；小学低年级、高中 **保主线可用**。

---

## 2. 任务清单

- [ ] 按《中小学人工智能通识教育指南》梳理**四学段知识树**（人工，先写大纲）
- [ ] 每学段产出 Markdown 章节文件（放到 `server/knowledge/<grade>/`）
- [ ] 每个文件头部写 **YAML front-matter 元数据**（见下）
- [ ] `server/knowledge/manifest.json`：知识点主表 + 依赖关系（`from → to, relation`）
- [ ] AI 批量生成讲解文本的脚本（可选：`scripts/gen_content.py`）
- [ ] **人工抽检记录**：抽检比例、发现的问题、修正（→ 报告素材）

### 元数据 schema（必须与第 8.2 节 DDL 字段对齐）

```yaml
---
grade_level: junior            # primary_low | primary_high | junior | senior
chapter_title: 走进人工智能
section_title: 什么是机器学习
knowledge_point: ml_intro
content_type: concept          # concept | example | practice | ethics
token_count: 420
dependencies:                  # → knowledge_dependencies 表
  - from: data_concept
    to: ml_intro
    relation: prerequisite
  - from: ml_intro
    to: decision_tree
    relation: prerequisite
---
正文 Markdown ...
```

## 4. 验收标准（DoD）

- [ ] 四学段均有内容，**每学段至少 8–12 个知识点**
- [ ] 每个 chunk 的 `grade_level` / `knowledge_point` 标注完整，无空字段
- [ ] `manifest.json` 中依赖关系的 `from`/`to` 都能在知识点表中找到（无悬空引用）
- [ ] **抽检通过**：随机抽 20% 内容人工核对，事实性错误已修正（留记录）
- [ ] 小学低年级文本不含超纲术语；高中文本不出现"小朋友"这类错位语气

---

## 5. 陷阱与注意

| # | 陷阱 | 说明 |
| --- | --- | --- |
| 1 | **内容编写耗时失控** | 这是拖垮全盘的头号风险。**必须** AI 批量生成 + 人工只定骨架与抽检。 |
| 2 | 元数据字段随手改 | 必须与执行文档 8.2 的 DDL 字段严格对齐，否则 S06 导入报错。 |
| 3 | AI 幻觉 | 知识点陈述必须人工核对；数字/定义类内容重点查。 |
| 4 | 学段错位 | 低年级用"算法""特征向量"会失分；跨学段复用要改写而非直接搬运。 |
| 5 | token 超长 | 节级 chunk 控制 **300–600 token**，超长要拆。 |
