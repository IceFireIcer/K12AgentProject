# 报告素材（Report Material）

> **用途**：从 D1 起，每天留 30 分钟把当天的**截图 / 关键决策 / 踩坑与解决**丢进这里。
> **为什么**：第 15 天没有额外时间"开始写报告"，只能"汇编"。素材不攒，报告就写不出来。

**目录约定**：

```
docs/report-material/
├─ decisions.md      # 技术决策记录（决策 + 理由 + 被否决的方案）
├─ pitfalls.md       # 踩坑与解决（直接喂给报告第 7 章与答辩问答）
└─ shots/            # 截图（学段对比、异常降级、状态流转图等）
```

这类图**必须在确认窗口正确前置后再截，并当场核对内容**，存 `shots/`。
