# 演示模式（演示驾驶舱 · 机制浮窗 · 轮次诊断信封）

> 本文是**拍摄与答辩的操作说明**，不是规格来源。规格与验收口径以 `项目执行文档.md` 为准；
> 产品内的文案与数据来自 `desktop/src/renderer/src/components/diag/evidence.ts`
> 与主进程的 `TurnDiagnostics`（`desktop/src/shared/diagnostics.ts`）。
>
> ★ **「预置演示数据」这一功能怎么落地**（一键载入 / 退出、三轮脚本、字段级预置清单、拦截点与测试）见
> [`docs/演示沙箱实施计划.md`](./演示沙箱实施计划.md)；本文只管**怎么用它演示**。

## 一、它是什么（三层，一份数据）

| 层 | 在哪 | 用来干什么 |
| --- | --- | --- |
| 轮次诊断信封 | 主进程（`agent/diagnostics.ts`） | 每轮结束推一份结构化证据：提示词拼装、画像指纹、学段观察、四级检索链、安全三阶段、工具调用、拦截记录 |
| 演示驾驶舱 | 「我的记录 → 演示驾驶舱」（**只在演示档可见**） | 总览与答辩讲解：左轮次时间轴 / 中十二个分块 / 右原始信封 |
| 机制浮窗 | 对话页「本轮机制」、编程 / 动画 / 练习卡片上的「机制」 | 在真实页面里**就地**解释这一步背后发生了什么（只读） |

★ 三层共用同一份 `TurnDiagnostics` 与同一套渲染件，所以浮窗说「3 次调用」，驾驶舱里就是 3 次。

## 二、怎么进去（四步）

1. 设置 → 高级设置（教师 / 家长）→ **进入演示驾驶舱**（同时把档位切到最高档）。
2. 设置 → 「隐私与本地服务」→ 展开「技术详情」→ **载入示例数据**：应用切进内存态的演示沙箱并**自动重载界面**（约 1 秒）。
   重载完就是一个「用了两个月的学生」—— 画像、掌握度、闯关进度、学习记录、错题、
   三条历史对话、动画库、设置页里的模型配置全都就位；题库 / 模板 / 知识点名这类随包内容照旧是真的。
   按钮这时写着「退出示例数据」（按下态高亮），**再点一次**就退出沙箱、重载回真实状态。
3. 想就地解释时：对话页顶部「本轮机制」，或卡片上的「机制」（教师 / 演示档才出现）。
4. 演示结束：驾驶舱顶栏「一键清空」（清内存环形缓冲 + 落盘记录，幂等）。
   ★ 用过演示数据的话，**先点一次「退出示例数据」**（设置 → 隐私与本地服务 → 技术详情）再收尾（理由见第八节）。

## 三、开始之前（每次都要做的四件事）

- `npm run ux:reload`（改过代码的话；HMR 不会重跑 `onMounted`）。
- 断网演练一次：确认检索降级链**逐级可触发**、提示仍可读。
- 两个学段各准备一段对话（同一个问题在小学与高中各问一遍）。
- 演示学生：默认 `student_001`；要用专用演示学生就设 `K12_STUDENT_ID=<id>` 再启动
  （身份由主进程解析，界面上切不了 —— 这是刻意的）。

## 四、三幕叙事（约 8 分钟，评分权重排序）

### 第一幕 · 产品演示（约 40%）

用学生视角正常使用：提问 → 动画卡 → 编程卡 → 练习闯关。
这一幕**只看好看**：浮窗保持关闭（它默认就是关闭的），不提任何技术词。

### 第二幕 · 幕后揭秘（约 40%）

以**一次提问**为主线，例如「老师，循环是怎么工作的？」：

1. 聊天页正常回答，逐字显示；
2. 点「本轮机制」→ 浮窗给出这一轮的摘要（提示词体量 / 学段 / 画像指纹 / 工具 / 安全三阶段 / 拦截记录）；
3. 点「在演示页打开」→ 驾驶舱跳到这一轮，左栏时间轴高亮；
4. 中栏自上而下讲：输入与安全预检 → 学段观察 → **提示词拼接**（七段 + 画像 + 权威段，逐段展开原文）
   → 画像注入与**逐字节稳定** → 工具调用 → **教材检索四级链**（试了哪几级、哪一级命中、学段过滤原文）
   → 内容安全三阶段（含「先流式显示、终审后整段撤回」）→ 沙箱（`while True: pass` 被真正中断）
   → **拦截记录**（跨轮累计）；
5. 右栏原始信封展开：证明上面每一个数字都是**运行时真的产生的**。

### 第三幕 · 工程保障（约 20%）

- 契约防漂移：现场改 `server/app/contracts.py` 一处字段 → `npm run check:api` 报红；
- 架构守卫：在渲染进程里 `import 'node:fs'` → `npm test` 的 G2 报红；
- 变异验证：`npm run guards:mutation`（66 条全红才算「守卫真的在守」）；
- 运行时：本地数据服务的连接状态（驾驶舱「运行时」分块）；
- 轨迹：`docs/tool-trace.mmd`（工具调用轨迹图，退出时由主进程导出）。

结尾回对话页开浮窗收束：
「刚才那 90 秒里发生的事，学生一个都看不见；这个浮窗和驾驶舱能把它全部摊开给你看。」

### 演示数据怎么用（载入之后的行进路线）

对话页是主戏 —— **演示者随便打什么、按发送就推进一轮，屏幕上出现的是脚本里那句**：

| 第几轮 | 你会看到 |
| --- | --- |
| 1 | 脚本那句学生原话 + 正文 + 两条教材引用 + **一张能播的动画卡** |
| 2 | 脚本那句学生原话 + 正文 + **一张编程卡** |
| 3 | 脚本那句学生原话 + 正文 + **一张闯关卡** |

放完第 3 轮**循环回第 1 轮**；开场卡那颗「好啊，就从这里开始」只是把一句话预填进输入框，按发送照常推进。其余地方随便点，处处有东西：

- 侧栏三条历史对话**点开都能回看**，其中「循环是怎么工作的」那条**带着当时的动画卡**；
- 学习记录五个分页 / 闯关 / 编程 / 动画 / 知识图谱 / 设置页**处处有数据**（空态文案一处都不出现）；
- 设置页的模型配置看起来「早就配好、一直在用」，但 **「连通性探测」与「拉取模型清单」两颗按钮是禁用的**
  —— 不伪造一次没发生过的外呼；
- 驾驶舱：三轮信封**逐轮出现**，第 3 轮带一条**拦截记录**。

## 五、必须演到的非正常路径

降级（断网 → 检索落到 FTS5 / 大纲）· 拦截（入口预检命中，**模型一个字节都没收到**）·
拒绝（学段冷却期间不接受自动调整）· 重启（关掉应用再打开，诊断记录**结构与结论还在、正文不在**）·
断网（全程无外网，回答仍可读）。

## 六、两条「不许说」的话（承诺文案不得超出实际行为）

1. **不要说「前缀缓存命中率 100%」**：供应商侧命中率不可观测。可以说的是
   「画像块字节指纹与上一轮相同，前缀字节稳定，具备被复用的条件」。
2. **不要说「模型推理我们都看得见」**：拿不到就是拿不到（界面如实写「没有拿到模型推理增量」）；
   拿得到时也是**默认折叠**、含敏感形状时**整段丢弃**（不做局部遮盖）。

★ **对外口径**：界面里除了驾驶舱那颗按钮，**没有任何「演示中」的标注** —— 这是有意为之；
被评委或观众问到时，**口头说明这是预置数据**即可（退出沙箱即还原，真实记录一个字节都不动）。

## 七、素材清单

- 终端录屏：`npm test` / `npm run guards:mutation` / `check:api` 报红那三段；
- 分屏：一侧界面（浮窗 + 驾驶舱），一侧代码（提示词拼装、检索链、安全门）；
- `docs/tool-trace.mmd`（已有导出物）+ 驾驶舱的「导出演示包」（Markdown：脱敏信封 + 轨迹图）；
- 断网截图、两个学段各一张对比截图、死循环中断那一下的截图。

## 八、常见坑

- **演示前忘了 `ux:reload`**：HMR 之后 `onMounted` 不重跑，浮窗入口可能还是旧的；
- **落盘的是脱敏版**：重启后回放看到「结构与结论在、正文不在」是**刻意的**（与「SQLite 不存对话正文」同一条纪律），
  别把它当成 bug 去改；
- **探针需要人先切到演示档**：`npm run ux:demo` 只量几何，不会替你点那个开关（档位是防误入机制的一部分）；
- **演示数据的开关是内存态**：关掉应用再打开自动回普通态（防「演示完忘了关」）——
  所以**每次演示前都要重新载入一次**；
- **沙箱态下再重载界面 / 点开历史会话，脚本进度会归零**：预置内容从不落盘，重载后从第 1 轮重新开始；
- **沙箱态下预置轮次不分叉**（没有「从这里重新问」）：预置轮次没有对应的会话记录可落，
  不给按钮比点了再回绝更诚实 —— 那是刻意的，别当 bug 修；
- **沙箱态下点写操作会回一句「这一项在当前状态下暂不可用。」**（保存设置 / 判分 / 新建会话这类）：
  那是设计而不是故障 —— 真实数据一个字节都不动；
- **演示结束点「退出示例数据」再走**（设置 → 隐私与本地服务 → 技术详情）：不然下一次打开还是普通态，而你会以为还在沙箱里。
