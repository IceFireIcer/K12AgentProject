# 演示沙箱（预置数据）实施计划

> **状态**：待实施（2026-09-26 定稿）·**规格权威**仍是 `项目执行文档.md`，本文是这一功能的实施方案。
> **相关**：`docs/演示模式.md`（怎么演示）、`docs/report-material/decisions.md` 的 D-093 / D-094 / D-095 / D-096。
> **一句话**：让现场演示看起来像「一个已经用了两个月的真实学生」，而真实数据一个字节都不动。

---

## 一、摘要与成功标准

在演示驾驶舱（`views/Demo.vue`，只在 debug 档可达）顶栏加一颗按钮「载入演示数据 / 退出演示数据」：

1. 点击 → 主进程进入**内存态演示沙箱** → 自动重载界面（约 1 秒）→ 学生态全部换成预置数据、内容态照旧走真实资产；
2. 对话由**写死的三轮脚本**驱动：演示者随便打什么、按发送就推进一轮（显示的是脚本里那句），放完**循环回第 1 轮**；
3. 再点一次 → 退出沙箱并重载回真实状态。

**全程不经过 Pi、不落盘、不写任何真实数据**；预置内容里不出现「演示 / 回放 / 预置 / 假数据」字样（按用户口径**完全无痕**，界面唯一指示就是那颗按钮本身，按下态高亮）。

**成功标准**

- 断网 + sidecar 未就绪也能完整演示（覆盖层接在 HTTP 端点检查**之前**）。
- 进出沙箱前后，`<userData>/students/` 与 `turn-diagnostics.jsonl` 的**大小与 mtime 一字不变**。
- 每个页面都不出现空态文案（学习记录写「还没有掌握度记录。」、编程页写「学习路径里还没有关卡」这类都不允许出现）。
- 模型配置看起来「早就配好、一直在用」，但**绝不伪造外呼成功**（探测类动作改为禁用）。

## 二、两条贯穿全局的分类原则

| 类别 | 例子 | 沙箱态行为 |
| --- | --- | --- |
| **内容态**（随包资产，与谁在学无关） | 题库（684 题）/ 代码模板（228 份）/ 动画模板（206 份）/ 知识点中文名 / 知识库统计（593 分块 · 8 章 · 483 依赖边） | **一律透传真数据**（不预置）。演示里播的动画、做的题、读到的模板全是真的 |
| **学生态**（这个人用过的痕迹） | 画像 / 掌握度 / 闯关进度 / 学习报告 / 错题 / 学段 / 章节 / 会话 / 动画库 / 诊断信封 / **模型配置显示态** | **全部预置**（见第三节清单） |

> 这条分界是判据，不是风格：内容态一旦被假掉，演示里就会出现「假题目配假答案」这种一戳就破的东西；而学生态不预置，页面就是空的。

## 三、预置数据清单（字段级 + 自洽数值）

> ★★ **所有数字必须互相解释得通**，且**所有 `kp_id` 与章节名必须真实存在于随包资产里**（否则界面会出现「未命名知识点」）。
> 下面给出一组**建议值**；改动任一数字都要同步 `tests/demo-seed.test.ts` 的自洽断言。

### A. 应用外壳

| 位置 | 显示 | 来源 | 预置值 |
| --- | --- | --- | --- |
| 侧栏头像 / 昵称 | 「小 小同」 | `student:get` | 昵称「小同」 |
| 侧栏学段位 | 初中 | `student:get` / `grade:get` | `junior` |
| 顶栏模型 chip | DeepSeek · deepseek-v4-flash | `settings:read` | 已配置态（见 E） |
| 顶栏学段 chip | 当前：初中（本地规则判定） | `grade:get` | `source: 'rules'`、冷却 0 |
| 章节指示器 | 正在学：第 N 章 … | `chapter:get` | **章节名取自真实章节清单** |
| 历史对话 3 条 | 标题 + 条数 + 时间 | `session:list` | 「循环是怎么工作的」「那用代码试试」「这几道题我错了」；**点开可回看**预置问答 —— 其中「循环是怎么工作的」那条回看时**带一张动画卡**（见下「B′」） |

### B. 对话页

- **空态开场引导**：一句自然的引导（指向第 1 轮的知识点）；点「好啊，就从这里开始」也会推进脚本。
- **三轮脚本**（学生原话 / 回答正文 / 引用 / 卡片 / 该轮诊断信封）：

| 轮 | 学生原话 | 展示 | 该轮信封 |
| --- | --- | --- | --- |
| 1 | 老师，循环到底是怎么工作的？ | 初中口径正文（约 150 字，无技术词）+ **两条教材引用**（`degraded=vector`）+ **动画卡** | `rag_search` 142ms；四级链 vector 命中 |
| 2 | 那我们用代码试试？ | 正文 + **编程卡**（`scaffold` 两处 `# TODO`、`expectedOutput` 形如 `1 2 3 4 5`） | `get_code_template` 21ms + `evaluate_code` 890ms；沙箱事件 `{codeExecutedIn:'renderer-worker', interrupted:true}` |
| 3 | 我想做几道题检验一下。 | 正文 + **闯关卡**（3 题）+ **掌握度进度卡**（+0.15 → 62%） | `generate_quiz` 620ms + `submit_quiz`；**一条拦截记录**（学段冷却剩 4 轮） |

#### B′. 预置对话里必须看得见动画（用户 2026-09-26 追加口径）

> 原话：「演示预置设计里面的对话里面也要体现动画，要有动画卡片什么的。」
> 这一条对**两条对话表面**同时成立，缺一条都算没做：

| 表面 | 要求 | 落地方式 |
| --- | --- | --- |
| **三轮脚本**（演示时现放） | 第 1 轮回答里**有一张能播的动画卡**（不是截图、不是占位） | 卡片载荷走**真实动画模板**（`preset-content/animations/` / 随包 `resources/templates/` 里的 slug），经真实 `readAnimationCard` 投影 —— 内容态一律透传真资产（第二节的分界） |
| **历史会话回看**（点开侧栏那条） | 「循环是怎么工作的」回看时**也有一张动画卡**，与当时那轮问答摆在一起 | `session:state` 的沙箱分支在**助手那条消息**上多带一个可选 `cards` 数组；渲染侧 `restoreConversation` 收到就把它挂到那一轮（与 live 路径共用同一套卡片投影，**不新写一份渲染**） |

★ **为什么不能只做三轮脚本**：现场演示最常见的动作是「点开历史对话看一眼」——
如果那三条点开全是纯文本，动画就只在「刚好放到第 1 轮」时出现，等于把这一条押在了
演示者的手速上。用户点名要的是「对话里面也要体现动画」，历史回看是**对话的一部分**。

★ **不动真实会话的口径**：`cards` 是**可选**字段，真实会话文件（Pi 的 JSONL 条目）里
根本没有它 —— 所以真实历史的回看**仍然是纯文本**（`api/events.ts` 那条「不恢复当时的卡片 /
引用 / 降级档位」的决策不变，本条只是给**沙箱预置**开了一个显式的数据口）。
沙箱态下点开历史会话时，`session:state` 只回预置内容，绝不读真实会话文件。

★ **不许伪造资产**：动画卡里的动画必须是随包真模板（`Sandbox.ready/play` 那套）；
模板缺失时按既有降级路径显示 fallback 文案，**不允许**为了演示新造一份动画或截图充数。

- **右栏（ContextRail）**：掌握度列表 5 条（带知识点中文名）、推荐下一步（带掌握度）、学段三路信号、最后一次检索降级档位（`vector`）、工具轨迹（来自三轮信封）。

### C. 学习记录页（五个分页全满）

| 分页 | 预置值 |
| --- | --- |
| 概览 | 平均掌握度 **62%** · 已掌握 **12 / 30** · 待加强 **7**；活动 **47**；答题 **45 / 58**（**78%**）；连续 **6 天**（今天已学）；徽章 `初通-3 / 熟练-6 / 精通-9`；7 天柱状图 **6 天有活动**（`daily` 之和 = 47） |
| 错题本 | 3 条（循环 / 变量 / 条件判断，错次 **6 / 4 / 3** → `total_wrong = 13`，正好等于 58 − 45） |
| 章节 | 5 章进度（与 `chapters` 字段一致） |
| 知识图谱 | 真实节点与边（内容态）+ 节点掌握度（来自预置掌握度） |
| 会话 | 与侧栏同源（3 条 + 搜索结果） |

### D. 闯关 / 编程 / 动画 / 知识图谱页

- **闯关页**：`stage_counts {locked 8, learning 6, quizzed 4, mastered 12}` —— **合计必须等于该学段真实关卡数**（实现时从真实依赖图节点数取，不写死）；当前 3 个 kp 的 stage 与徽章。
- **编程页**：至少 3 个可做关卡（预置进度 + 真实模板），题目标题用真实知识点名。
- **动画页**：内置模板（真实）+「我的动画」2 条（「循环的三种问法」「什么是变量」；详情用真实模板 HTML）。
- **「智团团给我出过的题」**：2 条（`quiz:generated-list`）。

### E. 设置页（含模型配置）

- 学生三节：学段初中、章节「第 N 章 …」、主题**深色**。
- 高级区：供应商 `DeepSeek` / BaseURL `https://api.deepseek.com` / Model ID `deepseek-v4-flash` / Key 显示掩码 `…9f3a`（`has_key=true`）；嵌入模式 `local_fastembed`（本机模型已就绪态）。
- **会外呼的两个动作在沙箱态禁用**：「连通性探测」「拉取模型清单」（按钮禁用 + 一句可读中文）。
- `settings:save` 在沙箱态**拒绝**；`auth.json` / `models.json` 全程不动。

### F. 演示驾驶舱与教师面

- 三轮信封：Prompt 三段拼装、画像字节指纹（第 2、3 轮与上一轮**相同**）、四级检索链逐级记录 + `gradeFilter` 原文、安全三阶段、工具调用；第 3 轮带一条拦截。
- 静态卡（四学段对比 / 隐藏机制 / 契约与守卫）本来就是静态，无需预置。
- 参考资料库页（教师面）：**不预置** —— 真实知识库统计本来就满。

### G. 明确不预置

题库、代码模板、动画模板、知识点名表、知识库统计、`/health`、设置外呼（探测 / 拉模型）、安全判定，以及任何会写学习数据的通道。

## 四、机制与拦截点

### 4.1 覆盖层（一处覆盖全部读路径）

- 新模块 `main/demo/overlay.ts`：`demoResponseFor(path, init): Response | null` —— 未激活 → `null`（**严格 no-op**）；命中**学生态读白名单** → 合成 JSON `Response`；其余一律透传。
- 接在 `bridge/client.ts` 的 `apiFetch` **最前面**（在 `endpoint === null` 检查之前）→ **sidecar 没起来也能演示**。

### 4.2 装配副作用防护（最关键的一处）

`grade:get` / `chapter:get` / `session:list` / `session:state` 的沙箱分支必须放在 `ensureChatRuntime()` **之前**，且**不写**模块级缓存（`currentGrade` / `currentChapter` / `lastSessionPush`）。

> 否则「进演示」会真的拉起 Pi 会话，甚至往会话 JSONL 里写一条开场白 —— 那就不是「不落盘」了。

### 4.3 写操作拒绝（IPC 处理器层，不经过 HTTP）

用既有的 `{ok:false,message}` 判别联合，统一回 `DEMO_BLOCKED_MESSAGE = '这一项在当前状态下暂不可用。'`：

`quiz:grade`、`chapter:set`、`grade:set`、`settings:save`、`code:run-hint`、`session:new|open|branch|delete`、`animation:saved-save|delete`、`knowledge:import|rebuild`。

> 放在处理器层而不是 HTTP 层：否则学生会看到「HTTP 409」这类状态码（守卫明确禁止把状态码印到学生页面上）。

### 4.4 对话与诊断

- `chat:send` 沙箱态 fail-safe 回绝；正常路径由渲染层在 `stores/chat.ts` 的 `send()` 里**吃掉**。
  - 分支位置：放在 `openingDismissed.value = true` 之后、`window.api` 检查之前 —— 那一段被 `ux-queue-and-scroll.test.ts` 的源码切片钉着，插错位置会把切片切空；分支内也不写 `localNotice.value = null`。
- `stores/demoSeed.ts` 的 `advance()`：用**脚本里的学生原话** `startTurn('demo-<n>', …)` → 事件回放 `citation → delta（18ms/字）→ 正文 70% 时投 payload → done`；每轮约 3–5 秒；`entryId / userEntryId / messageId` 恒为 `null`（预置轮次上不会出现「从这里重新问」）；退出或切页时清计时器，**不留 `streaming` 残留**。
- `diagnostics:read` 沙箱态返回预置信封；`diagnostics:clear` 沙箱态只清眼前那份（不碰磁盘）；`diagnostics:changed` 沙箱态不推送。
- **历史会话回看也带卡片**（B′）：`session:state` 的沙箱分支在助手那条消息上多带
  可选 `cards`；`restoreConversation` 认这个字段（真实会话不带 → 回看仍是纯文本）。
  卡片载荷与三轮脚本共用同一份常量（`main/demo/data.ts` 里只写一份），
  并同样按 `readAnimationCard` / `readQuizCard` / `readCodingCard` 投影。
- 演示页：沙箱态下轮次时间轴只显示已放过的轮次；「一键清空」= 脚本进度归零 + 清空时间轴。

### 4.5 开关与重载

- `demo:seed` 幂等：值未变 → 直接回执（不重载）；变了 → **先回执**，再 `setTimeout(80ms)` 对全部窗口 `webContents.reload()`（顺序反了回执会随重载丢掉）。
- 开关是**内存态**：关掉应用再打开自动回到普通态（防「演示完忘了关」）。
- 沙箱态下再重载 / 点开历史会话 → 脚本进度归零（预置内容从不落盘）。

## 六、测试与验收

### 6.1 新增 `tests/demo-seed.test.ts`

1. **自洽性**（本计划核心）：`daily` 之和 = `total_activities`；`quiz_correct ≤ quiz_total` 且 `total_wrong = quiz_total − quiz_correct`；`streak_days` 与 `daily` 里的「今天」一致；`badges` 与进度行的 `badge` 一致；`stage_counts` 之和 = 真实学段关卡数；掌握度条数 ≤ 真实知识点数。
2. **引用真实**：预置里出现的每个 `kp_id` 与章节名都能在真实资产里找到（用 `preset-content/quizbank/*.json` 汇总的 kp 清单做断言），防止界面出现「未命名知识点」。
3. **脚本可解析**：三轮文案与卡片能通过真实 `readCodingCard` / `readQuizCard` / `readAnimationCard`；事件序列喂真实 reducer 后得到期望 turn 状态（正文 / 引用 / 卡片 / `status === 'done'`）。
3b. **对话里必须看得见动画（B′，用户追加口径）**：① 第 1 轮那张动画卡解析出的模板 id **真实存在**于随包模板里（不是编的 slug）；② 预置历史会话里**至少有一条**带 `cards`，且回看后那一轮的卡片数 ≥ 1、kind 是 `animation`；③ **负向对照**：不带 `cards` 的（真实）会话回看后卡片数为 0 —— 证明这个口子只服务沙箱、没有改变真实历史的只读口径。
4. **学生可见文本四类检查**（补偿项，因为脚本在主进程、绕过了渲染进程的文件级扫描）：技术词、kp slug、未渲染 Markdown、破折号。
5. **模型配置态**：`has_key=true`、`api_key` 只匹配掩码形状、明文绝不出现在任何预置数据里；探测 / 拉模型的禁用分支存在。
6. **覆盖层负向对照**：未激活 → 任何路径都 `null`；激活 → 学生态读命中；内容态路径**不在**白名单里。
7. **装配防护**：源码级顺序断言 —— 四个处理器里沙箱分支在 `ensureChatRuntime()` 之前。
8. **零写入**：沙箱态遍历全部被拒通道 → 目标目录 / 文件 mtime 与大小不变。
9. **通道纪律**：三条新通道是 invoke、不在 `PUSH_CHANNELS`；计数与 `check:docs` 一致。

- 兜底：preload 桥缺方法 → 按钮禁用 + 一句学生话提示；sidecar 未就绪 / 断网 → 演示照常可跑。
