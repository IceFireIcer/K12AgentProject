## 每次开工前

1. 扫一眼 `docs/业务陷阱清单.md` 中对应模块的陷阱与验收口径。
2. 确认该票 `Blocked by` 全部完成；关卡类票未过关不进下一阶段。
3. 收工时：勾选验收条件、追加 `## 进度`、**当天做一次 git 提交**（`type(scope): 中文摘要`）。
