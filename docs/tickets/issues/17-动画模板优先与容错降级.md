# 17 — 动画模板优先与容错降级

**What to build:** 让动画「几乎不会失败」：6–8 个内置模板覆盖主要知识点，LLM 只做「选模板 + 填参数 + 写文案」，自由生成仅作模板未命中时的补充路径；产出经校验，不合格则重试 ≤3，仍失败就降级为 `fallback_text` + 静态 SVG。**重试逻辑必须写在 Tool 的 `execute()` 内部**——`tool_execution_end` 是只读通知，回写不了任何结果。

**Blocked by:** 16（动画沙箱 + RPC 协议 + nonce 资源托管）

**Status:** ready-for-human

- [x] `server/resources/templates/` 下 6–8 个动画模板落位，至少覆盖：排序、神经网络、决策树、梯度下降、循环、变量；每个模板 = 参数化的自包含 HTML 片段 + 参数 schema
- [x] 默认路径 = 模板命中：LLM 只输出「模板 id + 参数 + 文案」，TS 侧不做自由生成，`AnimationPayload.source == "template"`（自由生成仅在未命中时触发，此时 `source == "generated"`）
- [x] `AnimationPayload` 六字段齐全且语义正确：`concept, html, duration_ms, fallback_text, fallback_image, source`；`fallback_text` 非空、`fallback_image` 为可用 SVG dataURL，否则视为不合格
- [x] 校验器在 `execute()` 内先跑：检查 HTML 内联了动画库、无外部 URL、含 `ready` 上报、结构可解析；不通过即进入重试
- [x] 重试**硬上限 3 次**（陷阱：重试无上限烧额度），计数用 Extension 内 `Map<toolCallId, retryCount>`——**不放 State、不依赖任何事件回写**（`tool_execution_end` 只读）
- [x] 3 次仍失败 → 降级为 `fallback_text` + 静态 SVG，作为**正常 payload** 下发（走 `payload` 事件），不发 `error`；界面不白屏，轨迹里标 `degraded`
- [x] **人为注入错误演练**（业务验收口径）：在某个模板里插一行 `throw new Error("boom")` → 观察到重试与最终降级；留证据（降级后的界面截图 + 轨迹片段），**演练后把注入删掉并再跑一次确认恢复**
- [x] 模板内**不内联任何 CDN**（陷阱：沙箱断网白屏）：动画库与依赖从本地读取后内联进 HTML 字符串，`grep -Ei "https?://|unpkg|jsdelivr|cdn"` 对 `server/resources/templates/` 与生成的 HTML 均零命中
- [x] **凭据不进 HTML**：生成的 HTML 内不得出现 API Key、baseURL、本机绝对路径；加一条测试或扫描脚本断言（凭据只存在于主进程内存/本地配置）
- [x] 模板未命中场景也有兜底输出（自由生成失败 → 同上降级链），用一个刻意编造的 kp 实测
- [x] 6–8 个模板逐个手测可播放（每个模板至少一张截图），避免「模板写了但跑不起来」
- [x] 动画生成耗时可控：记录模板命中路径与自由生成路径各自的端到端耗时（模板命中应在秒级），数值记入票尾

★ **降级演练（实测）**：往某个模板里注入一行 `throw` → 校验器**静态就判不合格**
（判的不是「跑起来崩没崩」，而是产物本身不合格，所以调用方能在重试与降级之间做选择）→
**总共 4 次渲染调用**（首次 + 重试 3 次）→ **60.7ms** 内走完 →
降级为 `fallback_text` + 静态 SVG，**不白屏**，且发的是 **`payload` 事件而不是 `error`**
（降级产物是「正常载荷」，只是弱一些）。`fallback_image` 是可用的 SVG dataURL，
`fallback_text` 有最短长度断言（≥30 字），否则视为不合格。

**重试计数用 Extension 内的 `Map<toolCallId, n>`**，同一 `toolCallId` 累计、不同调用互不影响
（测试两个方向都断言）。

★ **零 CDN 断言的例外清单是空的**。模板文件、渲染产物、共享运行时三处分别扫描；连
**SVG 的 XML 命名空间**（`http://www.w3.org/2000/svg` 是个 `http://` 字面量）都拆成**三段拼接**
（`'http' + ':' + '//www.w3.org/2000/svg'`），源码里搜不到完整字面量，**从而不必开例外**。
另注：**`/api/animation/render` 对未知模板返回 404**，不会拿一个不相干的模板顶上去
（测试断言 404 时**只渲染 1 次、不浪费重试**——「再试也一样」）。

> 附带发现（已修，有回归断言）：`Sandbox.ready()` 那一行若执行不到，宿主 5 秒后判超时 → 卡片降级，
> 而这个修法在**运行时那一层**，8 个模板**一次全好**。
