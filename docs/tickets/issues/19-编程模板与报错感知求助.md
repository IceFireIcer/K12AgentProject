★ **报错感知**：`server/app/routes/code.py` 把 Pyodide 的 traceback 解析成面向学生的中文反馈，
覆盖 **4 类常见错误**（缩进错误、名字未定义、类型错误、索引越界）+ `ModuleNotFoundError`（matplotlib 被砍后的那条路）
+ `KeyboardInterrupt`（死循环中断），查不到类名也有兜底文案（**认不出类名不等于没有建议**）。
反馈**不拼原始 traceback**（原始 traceback 另有字段承载），且必经归一化格式。

★ **修掉一个真实的重复 bug（有回归断言）**：`_line_phrase()` 返回的是**完整短语**「第 3 行」，
而文案模板自带的占位符又包了一层「第 {line} 行」外壳——两处都拼，学生看到的会是
**「第 第 3 行 行附近的缩进不对…」**。这是**在真实 HTTP 回执的 `feedback` 字段里抓到的**，不是假想。
回归断言同时盯两头：既防重复（`not "第 第"` / `not "行 行"`），也防有人把 `_line_phrase` 改回返回纯数字。

★ **分级求助实测（1 → 2 → 3 逐级，同一 kp 内不跳级）**：
三级提示长度 **69 → 116 → 146 字符**，字数本身即「越往后越具体」的可量化证据；
**level 1 里不含任何可复制的代码**（只指方向）；级别**只升不降**（降级会让学生看到「退回」的怪现象）。
**连续失败 3 次触发主动介入**（`MAX_CONSECUTIVE_FAILURES` 是**唯一具名常量**，
测试会压缩到 2 次来验证；不新增第 7 个事件类型，走既有对话输出）。
失败计数**按 kp 与会话隔离、答对后清零**，换知识点不带上一轮计数。
