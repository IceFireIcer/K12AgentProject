# 20 — 学段自动推断规则引擎 + 建议条

**What to build:** 系统能察觉到「这个学生可能该换学段了」，并**以建议条形式请学生确认**，而不是静默切换。这服务 15% 创新性，且对未成年人产品而言「把控制权留给学生」是加分项。

**Blocked by:** 19 — 个性化闭环；12 — 知识点依赖图双用途

**Status:** ready-for-agent

- [ ] 四类信号提取：词汇复杂度（正则 + 术语表，不调 LLM）/ 问题深度 / 答题表现 / 元认知表达
- [ ] **第一层（每轮同步）**：规则检测，信号写 `grade_signals` 表
- [ ] **第二层（第 3 轮触发，不足则第 5 轮）**：独立轻量 LLM 判定，返回 `{suggestedAdjustment, confidence}`
- [ ] **最终决策权在规则引擎**，不在 LLM：置信度 **< 0.6 不调整**；连续 3 个信号同方向；调整后 **5 轮冷却期**
- [ ] **人工纠偏出口**：学生可随时显式重选学段，且重选后冷却期重置
- [ ] 显式选择过的情况下，推断**只写「建议」不直接改**
- [ ] 学生确认后写入 `grade_history(source=confirmed)`
- [ ] 判定结果原子写入 `learning.db` 的 `student` + `grade_history`
- [ ] System Prompt 在**下一轮**经 `before_agent_start` 自动更新，学生不感知「切换」动作
- [ ] 学段变化轨迹可用于教师 / 家长导出报告
