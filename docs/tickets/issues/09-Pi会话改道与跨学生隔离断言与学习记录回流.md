# 09 — Pi 会话改道 + 跨学生隔离断言 + 学习记录回流

**What to build:** 把 Pi 的会话落盘**显式改道**到 `students/<id>/pi-agent/`，用自动化断言守住「跨学生不混放」，并把学习记录从 `learning-log` Extension 经 HTTP 写回每人的 `learning.db`。为什么在这个顺序：08 已把 Extension 骨架与事件接好，本票才谈得上“写哪去”；它是合规硬伤项（K12 未成年人数据），也是 20（个性化闭环）与 23（重启后数据仍在）的前置。

**Blocked by:** 08 主 Agent + 6 Extension 骨架 + 轨迹导出

**Status:** ready-for-human

- [x] `agentDir` / `settings.sessionDir` 显式指向 `userData/students/<id>/pi-agent/`：Pi 默认写 `~/.pi/agent/sessions/--<cwd>--/`，不改道即**跨学生混放**（合规硬伤，AGENTS §5.8）
- [x] 自动化断言进 `desktop/tests/architecture-guards.test.ts`：跑完一轮对话后扫描磁盘，**`userData/students/<id>/` 之外不得出现本应用的 `.jsonl`**；同时断言 `~/.pi/agent` 在运行前后文件清单与 mtime 均未变化（未创建 / 未改写）
- [x] 切换学生（`student_001` → `student_002`）后，各自会话文件只落自己目录；两人对话内容互不可见（人工 + 断言各验一次）
- [x] `server/app/routes/students.py` 支持 `GET/POST /api/students`（新建含学段），落 `userData/students/`；**一人一库、不跨学生复用连接或数据**
- [x] `learning-log.ts` 经 `bridge/client.ts` → `POST /api/profile/{student_id}/events` 写入 `learning.db`，`activity` 覆盖 `qa | animation | coding | quiz` 四类
- [x] `learning.db` 的迁移器在 `server/app/store/` 里**幂等可重跑**（带 `schema_version`，重复执行不报错、不重复建表）；新学生首次使用时自动初始化（冷启动兜底）
- [x] 写入用 `studentId` + `sessionId` 关联 Pi JSONL 会话；**SQLite 不存对话正文**，只存从对话里提取的结构化学习数据
- [x] 重启应用后学习记录仍在：`learning_history` 行数不减少、`student.last_active_at` 更新（可查表验证，留 `sqlite3` 查询输出作证据）
- [x] sidecar 写库失败（进程未就绪 / 401 / 5xx）时 Tool 不崩：返回可读错误并计入 `error.degraded`，对话可继续
- [x] 报告素材记一条：跨学生隔离的验证方式（断言 + 人工检查命令），这是合规叙事的关键证据

## 进度

### ✅ 已交付（提交 `b72fa90`）

**三层隔离断言**（`desktop/tests/pi-paths.test.ts`，守卫 G9-*），一层比一层强：

1. **Pi 自己怎么看**：创建时查 `SessionManager.getSessionDir()` / `usesDefaultSessionDir()`，
   确认目录就在 `students/<id>/pi-agent/` 下、且**没有走默认目录**；
2. **磁盘上真的长什么样**：写完扫描磁盘，`students/` 之外出现任何本应用的 `.jsonl`
   → **抛 `SessionIsolationError`**（是 throw，不是 warn——合规项不允许只是「记一条日志」）；
3. **别人的 `~/.pi` 有没有被碰**：对 `~/.pi` 做运行前后快照（文件清单 + mtime + size），
   实测**连跑一次真实 Pi 之后仍是 0 处变化、7 个既有条目一个没动**（既有条目 mtime 停在 8/31、9/1，
   只要本应用碰过任何一个就会红）。

**断言本身被验证过会失败**：把目录故意指向 `students/<id>/` 之外时，
`captureIsolationError()` 确实抛出了 `SessionIsolationError`（测试里连「期望抛却没抛」也断言了）。

`learning_history.question` **每一行都是空**——SQLite 只存结构化学习数据，**不存对话正文**
（`store/learning.py` 的 `record_event()` 签名里 `question` 默认为 `""`，`session_id` 只做关联键）。
迁移器带 `schema_version`、**幂等可重跑**（按 set 命名空间分组，见票 10）。
