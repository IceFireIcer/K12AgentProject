**What to build:** 把 Pi 的会话落盘**显式改道**到 `students/<id>/pi-agent/`，用自动化断言守住「跨学生不混放」，并把学习记录从 `learning-log` Extension 经 HTTP 写回每人的 `learning.db`。为什么在这个顺序：08 已把 Extension 骨架与事件接好，本票才谈得上“写哪去”；它是合规硬伤项（K12 未成年人数据），也是 20（个性化闭环）与 23（重启后数据仍在）的前置。

**Blocked by:** 08 主 Agent + 6 Extension 骨架 + 轨迹导出
