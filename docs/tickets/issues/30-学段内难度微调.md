# 30 — 学段内难度微调（v4 新机制，单独设计）

**What to build:** 学段**不动**，在画像里加一档**学段内微调**（偏易 ← 正常 → 偏难），
它作用在「**怎么讲**」而不是「讲什么」：术语密度、例子的抽象层、先给结论还是先给推导。
目的是把自适应从**离散跳变**（换整套学段讲法）变成**连续调节**，同时完全不触碰已在跑的学段机制。

**Blocked by:** 25（标签体系地基）

**Status:** ready-for-human

> 为什么是 `ready-for-human`：这是 v4 档的**新机制**（执行报告 §5.3① 明说「单独设计与验收」），
> 「同一知识点、同一学段下，偏易 / 正常 / 偏难三档的讲法是否恰当」**必须人判断** ——
> 机器只能验「档位有没有按输入变、有没有越界」，验不了「这样讲对这孩子是不是更好」。

- [ ] 输入**复用已有数据**：`zpd_level` + 画像置信度（执行报告 §5.3①：微调的输入已经现成，不新增数据源）
- [ ] ★ **只影响讲法，不改学段**：不写 `student.grade_level`、不写 `grade_history`、不触发任何学段迁移；
  与学段规则引擎完全隔离（反向对照：同一段证据在微调前后，学段轨迹逐行相同）
- [ ] 档位有**上下界与可读反馈**：到顶/到底时给出人能看懂的说明，不静默钳制
- [ ] 教师视角可解释「这轮为什么讲得细 / 粗」（技术证据进 `<TeacherGate>`，学生面不出现档位名与内部字段，D-063）
- [ ] 与 `explain_style` / `pace` 的边界写清楚：学生**明说**的偏好永远压过系统微调（L2 > L3）
- [ ] 关闭开关时行为与旧版**逐字节一致**（默认关闭，直到人工验收通过）

## 人工验收（`ready-for-human` 的判据）

- [ ] 同一知识点、同一学段，人工抽检偏易 / 正常 / 偏难三档的产出：术语密度、例子抽象层、
  推导顺序三处**都能看出差异**，且偏易档不是「变简单题目」而是「换一种讲法」
- [ ] 抽检 3 个真实学生的过往问题：微调后的讲法在教师看来**更贴合该生**（不是统一变啰嗦）
- [ ] 与 D-020 的教训对照：微调**不覆盖**学生明说的偏好与手动学段
