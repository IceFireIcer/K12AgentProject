# 31 — 五问强制化（进对话流 / 删跳过 / 续问到 done）+ 概括真接线

**What to build:** 把票 26 落地的「五问冷启动」从**可选的底部卡片**改成**对话流里的强制流程**，
并把票 26 推迟的「后台概括」从降级桩换成**真调模型**的实现。

四条用户裁决（2026-09-29）：

1. **subagent：真接上** —— 不再留降级桩当默认；概括真的发一次模型请求。
2. **跳过：全链路删** —— 后端端点、IPC 通道、preload 方法、store 动作、界面按钮，一层都不留。
3. **`skipped`：也要接着问，直到 `done`** —— 历史的 `skipped` 只当「没答完」处理；
   `done` 是**唯一终态**。
4. **界面是唯一提问者** —— 引导期模型**不许再问一遍问句**（否则学生被问两次）。

**Blocked by:** 26（五问主链路）+ 07（设置页的 LLM 配置桥）

**Status:** done
