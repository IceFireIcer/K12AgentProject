# 21 — 学段自适应（自动推断 + 手动指定）

> **标题里的「建议条」已作废**：文件名保留只为不改依赖编号。

**What to build:** 双层学段推断，**决策权在规则引擎**。第一层每轮把四类规则信号写入 `grade_signals`（不调额外 LLM）；第二层在第 3 轮（证据不足则第 5 轮）跑**一次**轻量 LLM 判定产出 `{suggestedGrade, confidence}` —— 它**只是提议**：与规则同向时抬高置信度，**反向时被引擎直接否决**。达阈值即**自动切换学段**并原子写入 `student.grade_level` + `grade_history(source="inferred")`，由**下一轮**的 `before_agent_start` 装进 systemPrompt。★ **学生也可以手动指定**（指示器 / 设置页 → `POST /api/grade/override` → `grade_history(source="explicit")`），**立即生效**，之后 `MANUAL_COOLDOWN_TURNS` = 10 轮内不再自动调整。

**Blocked by:** 20（个性化闭环）、12（依赖图双用途）

**Status:** done（自动推断部分早先落地；手动指定部分 2026-09-17 由 D-037 落地）

- [x] 四类信号都能提取并写入 `grade_signals(session_id, signal_type, value, raw)`：词汇复杂度（术语表 + 正则，**不调 LLM**）、问题深度（规则 + 轻量 LLM）、答题表现（**服务端自己从 `learning.db` 读**，桌面端不上交答题数据）、元认知表达（「听不懂」「再讲一遍」等关键词）；`raw` 带**轮次锚点**（`t<n>|`）
- [x] 第一层每轮同步执行且不产生额外 LLM 调用（用一次对话的 provider 调用计数验证）；第二层在第 3 轮触发、证据不足则第 5 轮触发，两个轮次常量与 `rules.py` 有**跨语言一致性断言**（`desktop/tests/grade-inference.test.ts` 反向读 `.py` 常量）
- [x] 第二层返回 `{suggestedGrade, confidence}`，经 `server/app/grade/signals.py` 传给 `server/app/grade/rules.py`，**LLM 不直接改学段**；提议与规则**反向**时 `reason=llm_conflict`（造一条同向、一条反向的用例）
- [x] 规则引擎是**最终决策者**，四条硬约束各有单测：① `confidence < 0.6` 不调整（`0.59` 不改 / `0.60` 才进入后续判定）；② 连续 3 **轮**同方向信号（同一轮多条同向信号只算一轮）；③ 调整后 5 轮冷却期内不重复调整；④ 单次最多动 1 级（到顶/到底报 `at_boundary`）
- [x] ★ **两条写路径**（D-037）：① 自动 —— `POST /api/grade/turns/{student_id}`，规则引擎裁决，`source="inferred"`；② 手动 —— `POST /api/grade/override/{student_id}`，**学生指定，立即生效**，`source="explicit"`，之后 10 轮冷却。**断言**：`ChatSendRequest` 里没有 `gradeLevel`（G6c 钉死只有 `text`），手动走 `grade:set` 独立通道；`grade_history` **没有 `note` 列**（`PRAGMA table_info` 断言 —— 刻意不提供写不进去的字段）
- [x] 变更后**原子性写入** `student` + `grade_history(source, from_level, to_level, turn, confidence)`（同一事务），用 sqlite 查询输出作为证据；写库失败时**不改学段**并如实报 `reason=write_failed`
- [x] ★ **冷却窗口按来源推导、不加列**（D-037）：锚点 = 最近一条 `from_level` 非空的 `grade_history` 行，窗口 = 手动 10 / 自动 5。断言：手动后 10 轮内够格证据推不动学段（**反向对照**：同样证据在没 override 的学生身上**必须**改）；★ 锚点的 `turn` 用**当前轮次水位**（写 0 会让冷却剩余从 10 假变成 3 —— P-060）
- [x] 冷启动：无历史 → 默认**小学高年级**，且基线轨迹的 `from_level = NULL` —— **不算一次变更、不触发冷却期**（断言第 1–5 轮不会被误冷却）
- [x] **无 API Key 时第二层整层跳过**：第一层照常判定、照常能改学段，结果显式带 `degraded="no_llm"`（**降级不许静默**）
- [x] 自动判定**下一轮生效**：第 N 轮判定出的学段，由第 N+1 轮 `before_agent_start` 替换 systemPrompt；留切换前后的语气对比截图（同一问题、两个学段）
- [x] ★ **指示器可手动指定**（D-037）：`GradeIndicator.vue` 显示「当前：X」与**来源标签**（「手动选中」/「AI 引擎推算」），点开是四档（**默认收起**）；设置页有同一件事的第二个入口，**两处共享 `chat.setGrade`**。判定通道缺失时给出可读原因而不是永远停在「待判定」
- [x] ★ **在途判定不得覆盖手动选择**（D-037）：`grade.ts` 的 `epoch` 在采纳手动选择时 +1，上交任务 `await` 前后比对，不一致就丢弃结论；**反向对照**：不调 `adoptOverride` 时那条结论**必须**被采纳（P-061）
