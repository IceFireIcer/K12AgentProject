# 21 — 学段自动推断与建议条

**What to build:** 双层学段推断：每轮把规则信号写入 `grade_signals`（不调额外 LLM），第 3 轮（对话不足则第 5 轮）跑一次轻量 LLM 判定产出 `{suggestedAdjustment, confidence}`；**最终决策权在规则引擎**（阈值 / 方向一致性 / 冷却期）。推断**只写建议**，学生确认才落 `grade_history(source=confirmed)`；显式选择永远权威，且学生随时重选即重置冷却期。

**Blocked by:** 20（个性化闭环）、12（依赖图双用途）

**Status:** ready-for-agent

- [ ] 四类信号都能提取并写入 `grade_signals(session_id, signal_type, value, raw)`：词汇复杂度（术语表 + 正则，**不调 LLM**）、问题深度（规则 + 轻量 LLM）、答题表现（读 `learning.db`）、元认知表达（「听不懂」「再讲一遍」等关键词）
- [ ] 第一层每轮同步执行且不产生额外 LLM 调用（用一次对话的 provider 调用计数验证）；第二层在第 3 轮触发、对话不足 3 轮则第 5 轮触发
- [ ] 第二层返回 `{suggestedAdjustment, confidence}`，其数值经 `server/app/grade/signals.py` 传递到 `server/app/grade/rules.py`，**LLM 不直接改学段**
- [ ] 规则引擎是**最终决策者**，四条硬约束各有单测：① `confidence < 0.6` 不调整；② 连续 3 个同方向信号；③ 调整后 5 轮冷却期内不重复调整；④ **学生显式重选学段即重置冷却**
- [ ] 边界用例写死并断言：`confidence = 0.59` → 不改动；`0.60` → 才进入一致性判定；同一方向只来 2 个信号 → 不改动
- [ ] 建议条 UI（`desktop/src/renderer/src/components/` 内）在达阈值时出现，含「发现你连答对 3 题，要不要换成初中？」+ 确认 / 忽略两个动作；两条路径都实测
- [ ] 确认后**原子性写入** `student` + `grade_history(source="confirmed", from_level, to_level, turn, confidence)`，用 sqlite 查询输出作为证据
- [ ] 显式选择权威：学生手选学段后，推断只写建议不改值——断言 `student.grade_level` 不会被推断直接改写（造一次「该调但学生已显式选过」的用例）
- [ ] 下一轮生效且无感：确认后由 `before_agent_start` 在**下一轮**替换 systemPrompt；留切换前后的语气对比截图（同一问题、两个学段）
- [ ] `grade_history` 轨迹可读可展示，能支撑「第 3 轮判定为小学高年级（confidence 0.72），第 12 轮调整为初中（confirmed by student）」这类叙事
- [ ] 误判出口可演示：制造一次误判趋势 → 学生手选回原学段 → 冷却重置、建议条不再弹（留操作记录）
- [ ] 学段模板与四学段内容矩阵一致（语气差异，不只是难度数字）：`desktop/src/main/agent/prompts/` 四份模板各自被实际加载过（可在轨迹/日志中看到本轮使用的学段）
