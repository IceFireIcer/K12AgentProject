# 21 — 学段自动推断与自动生效（**不再有建议条**）

> **标题里的「建议条」已作废**：文件名保留只为不改依赖编号，**内容按 2026-09-16 的设计翻转重写** ——
> **学段完全自动推断、自动生效，没有人工选择入口，也没有「学生确认」这一步**（执行文档 §10 与 D-020）。

**What to build:** 双层学段推断，**决策权在规则引擎**。第一层每轮把四类规则信号写入 `grade_signals`（不调额外 LLM）；第二层在第 3 轮（证据不足则第 5 轮）跑**一次**轻量 LLM 判定产出 `{suggestedGrade, confidence}` —— 它**只是提议**：与规则同向时抬高置信度，**反向时被引擎直接否决**。达阈值即**自动切换学段**并原子写入 `student.grade_level` + `grade_history(source="inferred")`，由**下一轮**的 `before_agent_start` 装进 systemPrompt；学生端只有**只读指示器**（「当前：初中」/「待判定」）。

**Blocked by:** 20（个性化闭环）、12（依赖图双用途）

**Status:** ready-for-agent

- [ ] 四类信号都能提取并写入 `grade_signals(session_id, signal_type, value, raw)`：词汇复杂度（术语表 + 正则，**不调 LLM**）、问题深度（规则 + 轻量 LLM）、答题表现（**服务端自己从 `learning.db` 读**，桌面端不上交答题数据）、元认知表达（「听不懂」「再讲一遍」等关键词）；`raw` 带**轮次锚点**（`t<n>|`）
- [ ] 第一层每轮同步执行且不产生额外 LLM 调用（用一次对话的 provider 调用计数验证）；第二层在第 3 轮触发、证据不足则第 5 轮触发，两个轮次常量与 `rules.py` 有**跨语言一致性断言**（`desktop/tests/grade-inference.test.ts` 反向读 `.py` 常量）
- [ ] 第二层返回 `{suggestedGrade, confidence}`，经 `server/app/grade/signals.py` 传给 `server/app/grade/rules.py`，**LLM 不直接改学段**；提议与规则**反向**时 `reason=llm_conflict`（造一条同向、一条反向的用例）
- [ ] 规则引擎是**最终决策者**，四条硬约束各有单测：① `confidence < 0.6` 不调整（`0.59` 不改 / `0.60` 才进入后续判定）；② 连续 3 **轮**同方向信号（同一轮多条同向信号只算一轮）；③ 调整后 5 轮冷却期内不重复调整；④ 单次最多动 1 级（到顶/到底报 `at_boundary`）
- [ ] **自动生效、无人工入口**：`POST /api/grade/turns/{student_id}` 是学段的**唯一写路径**；断言仓库里**不存在**学段选择器与「学生确认 / 纠偏」端点（`GradeSelector` 不出现、`grade_history.source` **恒为 `inferred`**）
- [ ] 变更后**原子性写入** `student` + `grade_history(source="inferred", from_level, to_level, turn, confidence)`（同一事务），用 sqlite 查询输出作为证据；写库失败时**不改学段**并如实报 `reason=write_failed`
- [ ] 冷启动：无历史 → 默认**小学高年级**，且基线轨迹的 `from_level = NULL` —— **不算一次变更、不触发冷却期**（断言第 1–5 轮不会被误冷却）
- [ ] **无 API Key 时第二层整层跳过**：第一层照常判定、照常能改学段，结果显式带 `degraded="no_llm"`（**降级不许静默**）
- [ ] 下一轮生效且**学生无感**：第 N 轮判定出的学段，由第 N+1 轮 `before_agent_start` 替换 systemPrompt；留切换前后的语气对比截图（同一问题、两个学段）
- [ ] 只读指示器（`desktop/src/renderer/src/components/GradeIndicator.vue`）显示「当前：X」/「待判定」，**没有任何可点击的切换动作**；判定通道缺失时给出可读原因而不是永远停在「待判定」
- [ ] **误判的补偿机制可演示**（这是替代人工纠偏出口的机制）：连说三轮「听不懂 / 再讲一遍」→ 方向判定为**向下** → 自动下调一级；留 `grade_history` 轨迹与指示器前后对比
- [ ] `grade_history` 轨迹可读可展示，支撑「第 3 轮判定为小学高年级（confidence 0.72），第 12 轮自动调整为初中（inferred, 0.81）」这类叙事（**不要再写 `confirmed by student`**）
- [ ] 学段模板与四学段内容矩阵一致（语气差异，不只是难度数字）：`desktop/src/main/agent/prompts/` 四份模板各自被实际加载过（可在轨迹/日志中看到本轮使用的学段）
