# 21 — 内容安全终审链路

**What to build:** 不适内容不会停留在学生眼前——系统在生成结束后整段终审，违规则撤回该条消息并替换为安全提示，且**不拖慢首 token 的响应**。

**Blocked by:** 07 — 主 Agent + 6 个 Extension 骨架 + rag_search→citation

**Status:** ready-for-agent

- [ ] **输入侧**：敏感词 / 越狱意图轻量检查
- [ ] **生成侧**：流式输出 + **生成结束后整段终审**（终审在流结束之后做，**不阻塞首 token**）
- [ ] 违规处置：前端**撤回该条消息**，替换为 `blocked.safeText`
- [ ] 撤回体验有过渡提示（如「刚才的内容不适宜，已为你换成…」），不突兀
- [ ] 双重过滤：敏感词库（JSON，可扩展）+ LLM 自审 prompt
- [ ] **凭据脱敏第二道防线**：用 `before_provider_request` / `before_provider_headers` 在 provider 边界统一脱敏审计
- [ ] 确认 LLM 与嵌入调用**不明文写入日志**；日志脱敏过滤器保留 `%s` / `%(name)s` 占位符
- [ ] 数据合规：采集最小化，**不采集生物特征**
