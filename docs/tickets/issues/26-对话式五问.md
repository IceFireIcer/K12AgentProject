# 26 — 对话式五问（引导模式 + MVP 15 标签 + 后台概括）

**What to build:** 学生**第一次**使用时，用正常对话流问完五个问题（问句就是一条普通助手消息，
学生在输入框回答），本地抽取写进 `profile_tags`，产出 MVP 15 标签；五问收齐后**后台**跑一次概括
（fire-and-forget，不阻塞 UI）。五问**只跟学生走、不跟会话走**；`onboarding_state` 一旦离开
`not_started` 就**永不再弹**。

**Blocked by:** 25（标签体系地基：两表 + 白名单常量 + 守卫）

**Status:** ready-for-agent

- [ ] ★ **弹与不弹的唯一判据是 `onboarding_state === 'not_started'`**（`ONBOARDING_TRIGGER_STATE`）：
  新建会话不弹、画像空了不弹、手动定过学段不弹；跳过或完成之后任何新会话都不再问（守卫 G-I）
- [ ] 五个问句来自 `@shared/profile-tags` 的 `ONBOARDING_QUESTIONS`（**唯一一份**，主进程算 pendingQuestionId、
  渲染层渲染、测试断言三处同源）；问句作为**对话内的助手消息**出现，不是卡片，输入框照常可用
- [ ] ★ **回答归属靠位置，不靠解析**：渲染层记 `pendingQuestionId`，学生的下一条消息连同 qid 一起经
  `onboarding:answer` **独立通道**交给主进程；`ChatSendRequest` 仍然恰好只有 `text`（G-L / D-113）
- [ ] 每条回答**入库前必过 `sanitizePii`**：命中「我叫…」「XX 学校」「N 班」「手机号」等模式即**整条丢弃**
  并回落 `STUDENT_FALLBACK_NAME`，不做部分保留；脱敏后的原文落 `onboarding_qa`（一问一行，重答覆盖不追加）
- [ ] 真名只落 `identity_local.real_name`；**任何 prompt 都不读它**，模型全程只见到 `{{student_name}}` 占位符（G-C / G-D）
- [ ] 本地抽取产出 **MVP 15 标签**（12 维度表里 MVP 列 + 本地 4 个），每个键写前过 `isLlmVisibleTag`；
  不在白名单的候选**直接丢**，不报错、不降级成自由文本
- [ ] ★ **Q1 的点选当场写学段**：走既有 `grade:set`（`source=explicit`，立即生效 + 10 轮冷却），
  不等任何后端概括（D-112）；概括若给出不同学段**不得**覆盖学生明说的 explicit
- [ ] ★ **概括是 fire-and-forget**：经后台队列派发、8s 超时包装、失败最多自动重试 1 次、仍失败走
  `degraded`（只保留点选/本地映射得到的字段），**永不阻塞 UI**（守卫 G-J）
- [ ] 概括的输入**只有已脱敏的答案与候选标签**，绝不带原文以外的身份信息；产出的额外标签同样必须过白名单
- [ ] **降级不崩**：sidecar 不可用 / 断网时，这一问的落库失败**不打断引导**，五问照常走完，本地可点选字段仍在
- [ ] 通道按契约书 §3：`onboardingState` / `onboardingAnswer` / `onboardingSkip` / `profileTags` /
  `profileTagRetract` / `identityRead` / `identityFlagsSet` 七条 invoke，加 `onboardingChanged` **唯一推送**；
  回执一律复用 `CallResult`（失败也给一句可读中文，绝不让异常穿过 IPC 变成堆栈文本）
- [ ] 通道里**一个 studentId 字段都没有**：身份由主进程 `resolveActiveStudentId` 决定
- [ ] 合规：`learning_history.question` **仍然每一行为空**；普通学习记录 / quiz / animation / coding / 轮次诊断
  **仍然不存正文**（守卫 G-K；作用域只到 `onboarding_qa` 这 5 条）
- [ ] `npm run typecheck` 与 `npm test`（含 `desktop/tests/onboarding-guards.test.ts`）通过
