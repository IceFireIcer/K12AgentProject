★ **本票自己的测试抓出的三个真 bug**（都有回归测试）：

1. **`Number(null) === 0`**：模型返回 `{"score": null}` 时被判成 **0.0 分**并真的落库扣掌握度
   ——「没给分」被静默当成「零分」。修法是先排除 `null` / `""` 再转数值；
2. **关卡路径被 `DEFAULT_DEPTH=3` 截断**：深一层的知识点**永远不出现在关卡路径里**
   （`routes/quiz.py` 改用 `MAX_DEPTH_LIMIT`，并写了注释说明为什么不能用默认值）；
3. **推荐条目重复**：同一后继在推荐里出现多次。

主观题判分：prompt 内含**固定评分骨架 + 每题自带细则**（自由发挥的评分标准每次都会漂移一点，
连判三次就会得到三个分数）；`score` 限定在 5 档 `0.0 / 0.2 / 0.5 / 0.8 / 1.0` 上；
**但「多少分算过」由 Python 定**（`routes/quiz.py` 的 `SUBJECTIVE_PASS_RATIO`），
TS 只送 `score`、不送对错——两边各写一份判定就是迟早漂移。
