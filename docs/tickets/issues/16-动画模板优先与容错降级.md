# 16 — 动画模板优先 + 容错降级

**What to build:** 动画生成**失败也不白屏**——先尝试模板，失败则重试，重试耗尽后优雅降级为文字讲解 + 静态图。这是本项目自认的头号体验风险点（「一次性生成 HTML 失败率过高」）。

**Blocked by:** 15 — 动画沙箱 + RPC + nonce 资源托管

**Status:** ready-for-agent

- [ ] 内置 **6–8 个高质量动画模板**（排序 / 神经网络 / 决策树 / 梯度下降 / 循环 / 变量）
- [ ] LLM 只负责「选模板 + 填参数 + 生成文案」；自由生成仅作模板未命中时的补充路径
- [ ] 容错链：错误捕获 → **重试 ≤3**（硬上限，防死循环烧 API 额度）→ 降级 `fallback_text` + 静态 SVG
- [ ] **重试逻辑必须写在 Tool 的 `execute()` 内部**——`tool_execution_end` 是只读通知，不能回写结果
- [ ] 重试计数用 Extension 内 `Map<toolCallId, n>`，不要依赖事件回写
- [ ] **可现场验证**：往模板里注入一个 `throw`，观察自动重试并最终降级，**界面不白屏**
- [ ] 模板未命中的场景也有兜底输出
- [ ] `AnimationPayload.source` 能区分 `template` / `generated`
