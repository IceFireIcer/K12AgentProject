★ **日志脱敏实测（正反两面对照，`server/tests/test_safety.py`）**：
输入 `"检索失败 %s：key=%s 用时 %d ms"` + `args=("循环", FAKE_KEY, 12)`，
脱敏后 `record.getMessage()` 得到 **`'检索失败 循环：key=*** 用时 12 ms'`**
——**占位符全部保留**、`%d` 的参数仍是数字、Key 被掩掉；
`%(name)s` 命名形态同样存活（`'settings 保存失败：…'`）。
**反例**（直接 `record.msg = "***"`）会让 `record.getMessage()` 抛
`TypeError: not all arguments converted during string formatting`。
过滤器**永远返回 `True`**、且安装**幂等**（重复安装不会叠第二层）。
脱敏在 `main.py` **启动早期安装**。
