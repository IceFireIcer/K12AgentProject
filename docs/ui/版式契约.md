## 0. 基准：**正文 16px**（2026-09-18 整体抬升）

> 使用者是 **K12 学生**，会长时间盯着看。原来 14px 的中文在 1440 宽窗口上确实偏小 ——
> 阅读费劲、眼睛容易累，这是**用眼健康**问题，不是审美偏好。
> 所以整条阶梯一起抬了一档（不是只抬正文：只抬正文会让它顶到「次级正文」那一档，
> 层级差被吃掉，「标题比正文还小」会重新出现）。
> 容器尺寸跟着长：侧栏 248→264、顶栏 64→72、阅读栏 820→880。
> **行高** `--k12-lh-body` 1.7→1.75（字号变大后每行字数变少，行间距的绝对像素也变大，
> 1.75 让连续读三行的负担更轻 —— 长时间阅读的主要疲劳来源是**行间跳转**，不是单字大小）。

## 1. 字号阶梯：档位 = 用途，一一对应

写在 `src/renderer/src/assets/base.css` 的 `:root`（**唯一来源**，不要在页面里写 `font-size: 15px`）。

| token | 值 | 用途 | 反例（曾出错的地方） |
| --- | --- | --- | --- |
| `--k12-fs-2xl` | 32px | 仅对话页空态问候（全站唯一） | — |
| `--k12-fs-xl` | 24px | **页面身份行** / hero 数字 | 统计磁贴里的小数字不该用它 |
| `--k12-fs-lg` | 18px | 卡片 / 区块标题 | — |
| `--k12-fs-title` | 17px | **仅顶栏页面名**（chrome），不得用于内容 | 页面名不该比内容还重 |
| `--k12-fs-md` | 16px | 正文 | — |
| `--k12-fs-sm` | 14px | 次级正文、列表项、可读的键值 | — |
| `--k12-fs-xs` | 13px | meta、单位、脚注、主路径提示 | 这是 meta 的正确档位 |
| `--k12-fs-micro` | 12px | **仅角标（≤4 字）** | ✗ id / 标签 / 关系 / 层级徽标 / 说明文字 |

**判据（阶段 B2）**：`--k12-fs-micro` 只允许出现在**角标语义**的元素上，两条出路任选其一：

1. **选择器名含角标词** —— `badge` / `chip` / `tag` / `pill` / `count` / `num` / `dot` / `step` / `idx` / `key` / `mark` / `level`。
2. **在声明 micro 的那条规则里显式写 `k12-mark`**，例如：
   ```css
   .chat__compat {
     font-size: var(--k12-fs-micro);
     /* k12-mark：「跨学段兼容」是 5 字 chip —— 名字看不出是角标，标注给审计看 */
   }
   ```

其余一律用 `--k12-fs-xs` 起步。

> ⚠️ **为什么有第 2 条**：审计工具的第一版只用英文类名词表，于是
> `.qz__key`（选项字母 A/B/C）与 `.chat__compat`（「跨学段兼容」）这两个**真角标**
> 被判越界，被迫升级 —— 升完之后它们与相邻 meta 同权，
> 「这是角上的一个记号」这层意思**反而被抹掉**。**工具的判据在逼设计做坏事**，
> 所以改判据、留一条可 grep 的出口，而不是改设计去迁就工具。

> ⚠️ **抬升阶梯时三条关系必须重新核对**（最容易破的就是它们）：
> ① 顶栏页面名（`title` 17px）**严格小于**内容区身份行（`xl` 24px）；
> ② 正文（`md` 16px）严格大于任何 meta（`xs` 13px / `micro` 12px）；
> ③ `micro` 只给 ≤4 字角标，其余一律 `xs` 起步。

> 历史教训：11px 曾是全站**最高频**字号。用它写 id、关系、说明，
> 结果 meta 与角标同权、层级整个塌掉。

## 2. 阅读节奏：三档

写在 `base.css`（**唯一来源**）。

| token | 值 | 用途 |
| --- | --- | --- |
| `--k12-gap-block` | 20px | **块之间**：正文 → 步骤 → 要点 → 引用 → 卡片 |
| `--k12-gap-msg` | 36px | **消息之间**：一轮对话是一个单元 |
| `--k12-gap` | 16px | **卡片之间**（并列卡片） |

**段落之间没有 token**：行高 1.7 自身就产生了足够停顿，不要再加 margin。

> 依据：眼睛靠**间距差**分辨层级，不靠字号差。改造前对话页实测 ——
> 消息间距 20px 比段落的视觉间距（35.8px）还小，块间与段落同为 12px，
> 四个层级里三个挤在同一个值上。这是**节奏**问题。

## 3. 页面身份行 + 主路径提示

用共享组件，**不要各页自己写**（否则会立刻散开成 18/20/22）：

```vue
<PageIdentity
  main="这一页在讲什么"      <!-- 不是重复顶栏的页面名！ -->
  meta="统计口径 / 数据来源"  <!-- 可选 -->
  hint="先做什么，再做什么"    <!-- 主路径提示（D1），内容页必填 -->
/>
```

- `main` 落到 `.k12-identity__main`（24px/650），`hint` 落到 `.k12-path`（13px/muted）。
- **对话页例外**：不插身份行（正文才是内容），身份由空态 hero 承担。
  但空态 hero 的字号必须 ≥24px（它要压过顶栏 17px）。
- 规格页（`views/system/*`、`views/dev/*`、404）**不加**身份行与主路径提示。

**主路径提示示例**（写"怎么做"，不写"这是什么"）：

| 页面 | hint |
| --- | --- |
| 教材知识库 | 先按学段筛，再点行看分块详情 |
| 依赖图谱 | 先选根节点，再沿边看前置 / 后继 |
| 学习档案 | 先看 hero 的掌握度走向，再看下面三段叙事 |
| 闯关练习 | 先选关卡，再逐题作答 |
| 动画讲解 | 先挑模板，再在舞台上播放 |

## 4. 焦点规则（最高优先级）

> **内容区的最大字号元素必须是主对象，不能是 chrome。**

- 顶栏页面名 = 17px（chrome，退后）。
- 每个内容页内容区最大 ≥ 24px，且**严格大于** 17px。
- 卡片标题 18px、正文 16px 均在顶栏之上或附近，都不得**等于或大于**身份行。

守卫：`node scripts/audit-layout.mjs`（断言 7b）。

## 5. 材质与形状（沿用，不要新增第五层）

四层：`page` → `surface`（白卡）→ `surface-2`（卡内嵌入块）→ `float`（浮层）。
容器统一用 `<SurfacePanel>`（tone = card / inset / float / plain）。**不要 card 套 card。**

圆角四档 + 一档小元素：

| token | 值 | 用途 |
| --- | --- | --- |
| `--k12-r-inset` | 6px | 卡内嵌入块 |
| `--k12-r-card` | 10px | 卡片 |
| `--k12-r-control` | 12px | 按钮 / 输入（控件最圆） |
| `--k12-r-pill` | 999px | 胶囊 |
| `--k12-r-flat` | 4px | **极小元素**：角标 / chip / 代码片 / 引用行 |

## 6. 动效：本版为零

**不新增** `transition` / `animation` / `@keyframes` 装饰性动效。
只保留状态本身（`:hover` / `:focus-visible` 的颜色与描边变化），
且过渡必须用 `--k12-dur-state` + `--k12-ease-state`（不要自己写时长）。

> 目的：让设计只能靠材质、留白、字体层级与颜色站住 —— 动效会掩护静态缺陷。

## 7. 操作位置（阶段 D2）

| 位置 | 承载什么 |
| --- | --- |
| `PageActions`（页面顶部，吸顶） | **页面级**操作：导出、刷新、重建索引 |
| 卡片头 | **对象级**操作：这一条的展开 / 重命名 |
| 卡脚 | **状态提交**：保存 / 提交 / 运行 |

吸顶实现见 `PageActions.vue`；各页只需覆盖两个变量对齐自己的内边距：

```css
.pa { --pa-pad-y: 18px; --pa-pad-x: 22px; }  /* 规格页用 16px / 20px */
```

## 8. 可达性：模态必须收束焦点

抽屉 / 对话框 / 浮层打开时必须：**焦点移入 → Tab 在层内循环 → 关闭归还触发元素**。

```ts
const panel = ref<HTMLElement | null>(null)
useFocusReturn(panel, () => open.value)
```

配合既有的 `useEscape`（Esc 关闭）一起用。纯展示型浮层（hover 菜单）不要用。
