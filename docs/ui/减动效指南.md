# 减少动效：用户指南（学生 / 老师）

> 依据：`docs/optimise-report.md` §3.3（减动效增强，P2）· 落地：WP-10（2026-09-27）。
> 这一页写给**用这个应用的人**；实现口径见 `docs/ui/版式契约.md` §6.1 与
> `desktop/src/renderer/src/stores/reducedMotion.ts` 的文件头。

## 它是什么

打开「减少动效」后，界面**不再移动、不再循环**：页面切换的滑动、滚动动画、
转圈的加载指示、卡片悬停的抬升都会停下来或改用静态表达（静态亮点 / 只换阴影）。

**信息不会丢**：动画讲解会直接显示**演完的那一屏**（该出现的节点、字幕、步骤条都在），
只是不再有过程；加载中的状态仍然看得出来（静态亮点而不是转圈）。

## 怎么开

**设置 → 外观主题 → 减少动效**，三档：

| 档位 | 什么时候用 |
| --- | --- |
| **自动**（默认） | 跟随你电脑的系统设置。系统开了减动效，这里就跟着减 |
| **开启** | 系统没开、但你自己想要更安静的界面（对运动敏感、或者就是不喜欢动的东西） |
| **关闭** | 系统开了减动效，但你想要完整动效（比如演示给别的小朋友看） |

点一下**立刻生效，不用重启、不用刷新**；重启之后还是你上次选的那一档。

## 各处的表现（对一下就知道有没有生效）

| 位置 | 完整动效 | 减少动效 |
| --- | --- | --- |
| 闯关页翻题 | 平滑滚到下一题 | 直接跳过去（内容一样） |
| 动画讲解 / 动画卡片 | 逐相位演出 | 直接到最后一屏，可暂停 / 重播 |
| 加载中的转圈指示 | 旋转 | 静止的亮点 |
| 卡片悬停 | 轻微抬升 | 只换阴影、不位移 |
| 骨架屏闪烁 | 呼吸式闪烁 | 静止的灰条 |

## 老师 / 评委：怎么验它真的生效

```bash
# 应用带调试端口启动后（另一个终端）：
cd desktop
npm run ux:motion      # 用 CDP 模拟系统偏好，逐档验证「属性 + 动画时长 + 实时生效」
```

探针的判据是**动画时长本身**（挂一个 2s 的探针动画读计算值）：
减动效档下应压到 `0.01ms`，关闭档下应保持 `2s` —— 这比「数页面上有几个动画」可靠，
页面上本来可能一个动画都没有。

## 已知边界

- 沙箱里的动画（动画讲解 / 动画卡片）是**独立文档**，读的是它自己的系统偏好；
  在设置页切档时，动画卡片会重建一次 iframe 以立刻按新模式播（这是有意的）。
- 「关闭」档覆盖的是**本应用内**的减动效；系统级的其它动画（Windows 自己的过渡、
  别的软件）不受这里影响。
