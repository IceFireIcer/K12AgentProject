# 04 · 编程练习题（全新设计）

> 第三轮学生「我想用编程练练手」时挂的编程卡。
> **不复用** `server/resources/code-templates/machine-learning-sr.json` 里那道「算平均值与最大值」，
> **新写一道**与机器学习主题贴得更紧、且能让学生立刻理解「训练什么时候该停」的题。

## 1. 题目设计意图

机器学习训练有个核心问题：**什么时候该停？** 早停浪费算力，晚停过拟合。

学生通过这道题亲手算「连续两轮读数的变化量」，能直观感受到「稳态」的概念：
当变化量小于某个阈值，就可以停了。

这道题难度比「算平均值」高一档：要求用列表 + 循环 + 比较运算符，但**不需要函数 / 类**，
适合初学者在 5–10 分钟内做完。

## 4. 参考答案（不外发，仅落库供批改）

```python
readings = [42.0, 45.3, 47.8, 49.1, 49.6, 49.8, 49.9]

deltas = []
for i in range(1, len(readings)):
    deltas.append(readings[i] - readings[i - 1])

last_delta = deltas[-1]

if last_delta <= 0.5:
    print("进入稳态")
else:
    print("还在调整")
```

## 5. 期望输出（与 `expected_output` 字段对齐）

```

```

## 6. 测试用例（沙箱态批改口径）

| 用例 | readings | 期望输出 | 说明 |
| --- | --- | --- | --- |
| 主线（默认） | `[42.0, 45.3, 47.8, 49.1, 49.6, 49.8, 49.9]` | `进入稳态` | 题目默认参数 |
| 还在调整 | `[10.0, 14.0, 19.0, 25.0, 32.0]` | `还在调整` | 末轮 delta = 7.0 > 0.5 |
| 极端稳态 | `[50.0, 50.0, 50.0]` | `进入稳态` | 全程无变化 |
| 单点 | `[50.0]` | （参考答案会因 deltas[-1] 越界抛错；学生需处理边界） | 边界检查用例 |

最后一个用例不进沙箱默认展示（属于「加分题」），但参考答案的判分会跑——
告诉执行 AI：**沙箱预置不要包含单点用例**，只在真实判分端启用。
