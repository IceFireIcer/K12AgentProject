## 这套方案覆盖的事

1. **四轮对话循环**：问知识点 → 看动画 → 编程练手 → 我会了 →（循环回问知识点）
2. **安全审查可见**：循环到第 5 步故意打敏感词，学生气泡正常显示原话、助手气泡显示拦截回执
3. **动画卡片全新**：不复用 `gradient-descent`，新写一份基于 Stage API 的精美演示动画
4. **编程题全新**：不复用「算平均值」那道，新写一道与机器学习主题更贴的练习题
5. **动态生成题目预置**：generate_variants 的产物提前写好，沙箱载入即插
6. **全部其它数据配套**：从学段常量到学情报告，按高中第 3 章机器学习主题全表展开
