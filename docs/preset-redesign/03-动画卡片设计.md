# 03 · 动画卡片设计（gradient-descent-v2）

> 第二轮学生问「训练的时候，它怎么知道该往哪儿调？」时挂的动画卡。
> **不复用** `gradient-descent.json` 旧模板，**全新设计**一份基于 Stage API 的精美演示动画。

## 1. 设计意图

旧版 `gradient-descent` 是单点小球沿损失曲线滚——画面美但**信息量薄**：看不到训练数据散点、看不到「预测函数」长什么样、看不到「损失是从哪里来的」。

新版本把它们画在**一张图**上：左半是**训练数据散点云** + **当前预测直线**，右半是**损失曲线** + **小球追踪当前位置**。学生一眼能看懂「参数调一下 → 散点与直线的距离变 → 损失小 → 小球沿曲线下移」。

## 2. 画面结构

```
┌──────────────────────────────────────────────────────────────┐
│ 梯度下降：让损失降下去                                    │
│ 准备开始                                                    │
│                                                              │
│  [散点云区]                  │  [损失曲面区]                  │
│  · 真实数据点 + 拟合直线      │  损失 L(w) 曲线 + 小球       │
│  （随每步 w 更新而平移 / 转）  │  （小球沿曲线向谷底走）     │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

舞台固定 **720 × 420**（Stage API 视口），左右各占一份模块。每个模块自己有 readout。

## 3. 画面分区（精确坐标）

按 Stage API 的 `Sandbox.safe`（左 34 / 顶 34 / 右 34 / 底 30）：

| 模块 | x | y | w | h |
| --- | --- | --- | --- | --- |
| 左：散点云 + 拟合直线 | 50 | 70 | 320 | 280 |
| 左标题 | 50 | 50 | 320 | 22 |
| 散点云读数 | 50 | 360 | 320 | 24 |
| 右：损失曲面 | 410 | 70 | 270 | 280 |
| 右标题 | 410 | 50 | 270 | 22 |

散点云用 18 个数据点，按 `y = 2.2·x + 30 + noise` 生成（noise 是固定的 -8..8 序列）。拟合直线斜率固定为 2.2，截距随每步 w 变化（演示「参数变化 → 直线平移」）。

## 5. 9 个相位（时间线，按 gpt6.1 报告）

每个相位的 `caption`（字幕行）：

| 相位 | caption | step | 动画 |
| --- | --- | --- | --- |
| 1 | 先看这一批训练数据 | 1/4 | 18 个散点 stagger 入场（35ms 递进，r 从 0 长到 5） |
| 2 | 先给参数 w 一个起点 | 2/4 | 拟合直线从左到右延伸画出 |
| 3 | 算每个点的偏差，加起来就是损失 | 3/4 | 18 根偏差虚线整体淡入 + 损失读数显示 7.60 |
| 4 | 沿损失下降最快方向走第一步 | 4/4 | 第 1 步：w 0→1.68，loss 7.60→1.79 |
| 5 | 继续往下走，损失越来越小 | 4/4 | 第 2 步：w→2.42，loss→0.67 |
| 6 | 继续往下走，损失越来越小 | 4/4 | 第 3 步：w→2.74，loss→0.45 |
| 7 | 已经接近最低点，再走一小步 | 4/4 | 第 4 步：w→2.89，loss→0.41 |
| 8 | 继续调整，直线已经很接近数据趋势 | 4/4 | 第 5 步：w→2.95，loss→0.40 |
| 9 | 到达谷底，损失暂时降到最低 | 4/4 | 第 6 步：w→2.98，loss→0.40，小球 scale [1,1.08,1] 收束 |

总时长 8200ms（每相位动画段 460ms + holdMs 380ms；相位 1 因 stagger 总耗时 1055ms）。

## 6. 沿用 Stage API 而非手写 SVG

按 `STAGE-API.md` §3 至 §4：

- 用 `Sandbox.layout(plan)` 声明式建左右两区，每个数据点用 `Sandbox.node()` 建一个 `<circle>`（小节点，sub 是数据值）。
- 拟合直线用 `Sandbox.node()` 的极扁节点表示（h=4）。
- 损失曲线用 `Sandbox.layout` 的 `plots` 字段画一条 `<path>`。
- 小球用 `Sandbox.node({ w:18, h:18 })` 套上 `tone:'warn'`、`focus:true`。
- 时长取自 `Sandbox.motion.duration`（technical 皮肤 460ms、eased `easeInOutQuad`），不用写死。

## 8. 动画脚本（Sandbox.timeline 写法）

按现有 `Sandbox.play` + `Sandbox.timeline` 接口写。完整脚本见 `animation-preview.html` § 9（预览页面里的 `<script>` 段，可直接复制到模板 `script` 字段）。

骨架（参数：`{{steps}}` / `{{rate}}`）：

```js
var m = Sandbox.motion;
var STEPS = {{steps}};
var RATE = {{rate}};

// 散点云区
var DOT = 6;
var TRIAL = [
  [60,280],[100,250],[140,235],[180,230],[220,210],[260,200],
  [300,180],[330,190],[100,195],[140,180],[180,165],[220,160],
  [260,145],[300,130],[200,225],[240,210],[280,200],[320,170]
];

// 损失曲线：L(w) = 0.8·(w - 3)^2 + 0.4，最低点在 w=3
function loss(w){ return 0.8*(w-3)*(w-3) + 0.4; }

var left = Sandbox.layout({ /* 左半区 */ });
// ... 散点云 + 拟合直线 + 字段
Sandbox.play(function () {
  return Sandbox.timeline(STEPS + 1, function (tl, index, h) {
    if (index === 0) {
      h.caption('先看这一批训练数据');
      h.step(1, 4);
      return { targets: dotGroup, opacity: [0, 1], duration: m.duration, easing: m.easing };
    }
    if (index === 1) {
      h.caption('随便给一个初始参数 w');
      h.step(2, 4);
      return [/* 直线淡入 + 标注 */];
    }
    if (index === 2) {
      h.caption('算每个点的偏差，加起来就是损失');
      h.step(3, 4);
      return [/* 偏差虚线淡入 + 损失读数动起来 */];
    }
    h.caption('沿损失下降最快方向走一步');
    h.step(4, 4);
    return [/* 直线平移 + 小球沿曲线走 */];
  });
});

Sandbox.ready({ template: 'gradient-descent-v2', steps: STEPS });
```

完整脚本见 `animation-preview.html`（可直接打开看效果）。

## 10. 沙箱态下挂载方式

- `animation:render` 端点用 `gradient-descent-v2` 模板渲染出 HTML
- 沙箱态预置好这条 HTML（带真实 `payloadId`），脚本第 2 轮挂载
- 取不到时降级到现有 fallback（`gradient-descent.json` 的 fallback_text）+ 静态图

> ★ 沙箱态不保证模板文件存在于产品包——执行 AI 需要在落地时把模板文件加进 `server/resources/templates/gradient-descent-v2.json`，并跑一次 `gen:api` 让契约承认新模板 id。

## 11. 与旧版的兼容

`docs/preset-redesign/animation-preview.html` 可以直接用浏览器打开，看动画效果。它沿用了 `runtime.js` / `base.css` / `skins.css` 的真实形态——内联 anime.js v3、内联 sandbox runtime，单文件可跑。

## 12.1 v3 改进点（按 gpt6.1 执行计划报告）

| 项 | v1 / v2 | v3 |
| --- | --- | --- |
| 相位数 | 4 引导 + 6 走步混合 | 9 独立相位，每个走步独立 caption |
| 总时长 | 6500ms（提前结束） | 8200ms（与宿主进度对齐） |
| 小球结构 | 单层 | 三层：光晕 r=16（opacity 0.15）+ 主体 r=7 + 内核 r=2（var(--surface)） |
| 轨迹尾巴 | 单一 opacity 0.25 | 递减：最近 0.25 / 倒数第二 0.18 / 更早 0.12，最多 4 个 |
| 拟合度 | 写死梯度 | 教学映射 `fit = 0.42 + 0.53 * (7.6 - loss) / 7.2`，与损失同步 |
| 数学严谨 | 内部计算可能被显示值污染 | 内部 6 位小数，显示 2 位，按公式重算（与 PRD 旧表冲突时以公式为准） |
| 坐标映射 | 散点直接用数据值 | `screenX/screenY` 函数映射，左面板数据完整进入绘图区 |
| 文案 | 4 句循环 | 9 句独立（含「先给参数 w 一个起点」「已经接近最低点」「到达谷底」等） |
| 终点收束 | 无 | 相位 9 小球 `scale [1, 1.08, 1]`，视觉句号 |
| 面板标题 | 「训练数据」「损失曲面」 | 「训练数据与预测」「损失曲面 L(w)」 |
| 步骤条 | 「第 0 步」 | 「第 0 步 / 共 4 步」 |
| 数学轨迹验证 | — | 与报告 §5.2 表格逐值对齐（已 Node 验证） |
