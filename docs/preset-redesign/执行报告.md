### 3.1 时长预算差 2460ms（**最硬的一条**）

- `03` §5 / 报告 §7 都写 **总时长 8200ms**，并按「每相位动画段 460ms + hold 380ms」算出来 8155ms。
- **实测 `runtime.js` 的 technical 皮肤 `holdMs = 740`，不是 380**（`_shared/runtime.js` 的 `MOTION` 表）。
  真实时长 = 1055（相位 1 的 stagger） + 8 × (460 + 740) = **10655ms**。
- 后果：卡片右上角那个 `(view.durationMs / 1000).toFixed(1)` 的秒数徽标会显示 **8.2s**，
  而球实际滚 **10.7s** —— 演示里肉眼可见的自相矛盾。

| 选项 | 做法 | 代价 |
| --- | --- | --- |
| **★ A（建议）** | `duration_ms` 改成 **10655**（或取整 10700） | 与 `03` §5 / 报告 §15 的 `8200` 不一致，需在本文档记一笔「实测 holdMs=740 推导」 |
| B | 保留 `duration_ms: 8200`，压 hold 到 380 | 不能真的把 hold 写进模板（`Sandbox.timeline` 自动插 `motion.holdMs`，模板写不了 380）；除非 9 相位压成 7 相位，破坏 9 相位设计 |
| C | 保留 8200，接受徽标与实播不符 | 演示现场可被评委一眼看出 |

### 3.2 第 5 轮信封的拦截字段装不进类型

  `interceptions[0].stage='input'`、`category='illegal'`、`label='违法与危险品'`。
- **实测** `DiagInterception`（`desktop/src/shared/diagnostics.ts:101`）是 `{ source: string; reason: string; detail?: string }`
  —— **没有 `stage` / `verdict` / `category` / `label` 这四个字段**，照文档写会当场类型报错。
- 另外：真实 `guard.py` 里 `reason` 是**一句可读中文**（「命中内容安全规则：违法与危险品（制作炸药）」），
  `source` 才是 **`wordlist`** 这个标记 —— 文档 §7.1 把两者写反了。

| 选项 | 做法 |
| --- | --- |
| **★ A（建议）** | 不扩类型。写成 `{ source: 'wordlist', reason: '命中内容安全规则：违法与危险品（制作炸药）' }`；`stage='input'` 由同轮的 `safetyFinal.stages` 那条 `{stage:'input', verdict:'blocked'}` 承载（本来就有） |

| C | 只用 `reason`，丢掉 category/label | 与你文档里「category/label 与 sensitive-words.json 同源」的口径不符 |
