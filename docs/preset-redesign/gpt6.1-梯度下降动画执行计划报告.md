## 0. 一页结论

这张卡片讲的不是“一个球在曲线上移动”，而是一个完整的因果链：

> 训练数据出现 → 先给一个参数 → 直线产生偏差 → 偏差形成损失 → 参数沿下降方向更新 → 直线靠近数据 → 小球到达谷底。

视觉策略是**双面板、单主线、分层揭示**：左侧承载“数据和预测”，右侧承载“损失和搜索”。每次参数更新同时作用于左右两面板，学生可以把直线的平移与曲线小球的下移对应起来。

整体气质采用“工程蓝图上的暖色焦点”：

- `var(--accent)` 是数据与损失曲线，负责建立知识主线。
- `var(--warn)` 是当前参数和动作焦点，负责告诉学生“现在正在改哪里”。
- `var(--muted)` 只承担辅助解释，不与主信息竞争。
- 所有颜色只通过 CSS 变量和类名表达，不写死色值。
- 不使用渐变。曲线下方使用单色低透明度填充，保证断网和低性能环境下稳定。

## 1. 目标、非目标与硬约束

### 1.1 学习目标

播放结束时，学生应能用自己的话回答三件事：

1. 训练数据是一批带有规律、但不完全落在一条线上的点。
2. 参数变化会让预测直线平移，直线与点的距离随之变化。
3. 损失越小，曲线上的小球越接近谷底，预测直线越接近这批数据的整体趋势。

### 1.2 非目标

本卡片不承担以下内容：

- 不展示完整偏导推导。
- 不解释多维参数空间。
- 不把示意损失冒充真实数据集的 MSE。
- 不添加按钮、外链、远程字体、装饰性插画或额外色相。

### 1.3 必须遵守的运行约束

| 项 | 执行规格 |
|---|---|
| Stage | `Sandbox.stage()`，逻辑尺寸 720 × 420 |
| 动画库 | anime.js v3，内联使用 |
| 颜色 | 只使用 `var(--accent)`、`var(--warn)`、`var(--surface)`、`var(--surface-2)`、`var(--ink)`、`var(--muted)`、`var(--line)`、`var(--chip-bg)`、`var(--chip-fg)` |
| 字体 | 系统字体：`"Microsoft YaHei", "PingFang SC", system-ui, sans-serif` |
| 外链 | 零外链，不使用 CDN、远程图片、远程字体 |
| SVG | 创建元素时使用 `Sandbox.SVG_NS` |
| 文案 | 不出现 `**`、反引号、`——`、`…`、`...` |
| 宿主接口 | 由模板负责接入 `Sandbox.play`、`Sandbox.ready`，本报告只规定其内部执行内容 |
| 播放模式 | `Sandbox.timeline(9, builder)`，4 个引导相位加 6 个更新相位，总计 9 相位 |

## 2. 视觉概念与构图原则

### 2.1 视觉概念：一张工程草图，两种观察角度

左面板像一张“正在被修正的预测纸”：点是观测，橙线是当前猜测。右面板像一张“参数地形图”：蓝色曲线是损失，橙色小球是当前参数。

两面板不使用中间竖线分割。通过相同的顶部基线、相同的面板圆角和相同的底部读数带，让学生自然地把它们视为同一个过程的两个视角。

### 2.2 视觉节奏

- 入场：安静、逐点、从无到有。
- 解释：直线从左向右画出，形成“猜测被写上去”的感觉。
- 暴露代价：偏差虚线一次出现，让“损失”变得可见。
- 优化：每步动作短而明确，移动后留 380ms 观察停顿。
- 收束：小球在谷底轻微缩放一次，直线停止抖动，读数稳定在两位小数。

### 2.3 信息优先级

1. 当前小球与当前拟合直线。
2. 散点云与损失曲线。
3. 偏差虚线与最低点标记。
4. 坐标标注、辅助网格、说明标签。

任何视觉加分项都不能改变以上优先级。

## 4. 画布与精确坐标规格

### 4.1 外壳与舞台安全区

运行时的 SVG 是 `viewBox="0 0 720 420"`，标题、字幕、步骤条属于 `.anim-canvas` 外部 HTML。SVG 内容应全部落在 `Sandbox.safe` 内：

- 安全区左边界：34
- 安全区上边界：34
- 安全区右边界：686
- 安全区底边界：390

`Sandbox.readout` 是上下排布局，`h: 24` 不代表最终高度。technical 皮肤下，标签和 25px 数值加内边距后会自动长到约 81px。因此本方案把读数带整体放在 `y = 300`，实际底部约 381，给安全底边留 9px 呼吸。

| 右面板 | 360 | 34 | 320 | 254 | 损失曲线与小球 |
| 左面板内边距 | 20 | 14 | 280 | 220 | 绘图区和标题共用 |
| 右面板内边距 | 20 | 14 | 280 | 220 | 绘图区和标题共用 |

## 5. 数据与教学语义

### 5.1 固定数据

按 PRD 原样保留 18 个点：

```text
[70,178] [95,192] [120,205] [145,215] [170,225] [195,238]
[220,248] [245,255] [270,268] [295,278] [320,290] [100,188]
[150,218] [200,240] [250,260] [300,285] [115,200] [265,270]
```

点半径 5，opacity 0.85。

### 5.2 梯度下降轨迹

梯度为：

```text
dL/dw = 1.6 * (w - 3)
w_next = clamp(w - 0.35 * 1.6 * (w - 3), 0.05, 5.95)
```

按公式严格重算，实际轨迹如下：

| 状态 | w | b(w) | loss | 教学拟合度 | 球 x | 球 y |
|---|---:|---:|---:|---:|---:|---:|
| 初始 | 0.000000 | 154.000000 | 7.600000 | 0.4200 | 390.00 | 72.00 |
| 第 1 步 | 1.680000 | 140.560000 | 1.793920 | 0.8474 | 465.60 | 220.86 |
| 第 2 步 | 2.419200 | 134.646400 | 0.669863 | 0.9301 | 498.86 | 249.95 |
| 第 3 步 | 2.744448 | 132.044416 | 0.452245 | 0.9462 | 513.50 | 255.58 |
| 第 4 步 | 2.887557 | 130.899543 | 0.410115 | 0.9493 | 519.94 | 256.68 |
| 第 5 步 | 2.950525 | 130.395799 | 0.401958 | 0.9499 | 522.77 | 256.89 |
| 第 6 步 | 2.978231 | 130.174152 | 0.400379 | 0.9500 | 524.02 | 256.99 |

球坐标采用 `curveX(w)` / `curveY(loss)`，上表使用 `CURVE_AREA={390,72,270,194}`。

**重要实现决策**：PRD 表格中写的第 1 步 loss=2.13、第 2 步 w=2.62 与给定公式不一致。实现必须以公式为唯一真源，报告中的读数和球位置也以公式为准。如果产品方坚持原表数字，应同步修改公式后再实现，不能两者混用。

### 5.3 拟合度显示策略

拟合度是本动画的教学指标，不声称是由固定散点直接计算出的统计指标。推荐映射：

```text
fit(loss) = 0.42 + (0.95 - 0.42) * (7.6 - loss) / (7.6 - 0.4)
```

它保证初始值为 0.42，谷底约为 0.95，并与右侧损失同步变化。若需要更严格的统计语义，应另加“示意拟合度”标签，或改用真实回归指标。

## 6. 分相位动画执行表

### 6.1 时间参数

technical 皮肤读取：

```text
duration = Sandbox.motion.duration = 460ms
easing = Sandbox.motion.easing = easeInOutQuad
stagger = Sandbox.motion.stagger = 90ms
holdMs = Sandbox.motion.holdMs = 380ms
```

散点入场的专项 stagger 按 PRD 固定为 35ms，不覆盖全局 `motion.stagger`。

### 6.2 相位 1：散点云入场

**语义**：先让学生看到“数据长什么样”。

- caption：`先看这一批训练数据`
- step：`1 / 4`
- 播放区间：0ms 至 1,055ms
- 组成：18 个 circle 同时加入一个 anime 配置，按索引 stagger

```js
{
  targets: dotGroup,
  r: [0, 5],
  opacity: [0, 0.85],
  duration: m.duration,
  delay: anime.stagger(35),
  easing: m.easing
}
```

总耗时：`460 + 17 * 35 = 1,055ms`。相位结束后插入 `holdMs = 380ms`。

### 6.3 相位 2：拟合直线画出

**语义**：参数先随便取一个，模型先做一次猜测。

- caption：`先给参数 w 一个起点`
- step：`2 / 4`
- 初始 w：`0`
- 拟合度：瞬时更新为 `0.42`
- 播放区间：1,435ms 至 1,895ms

直线使用一条 line，而不是通过缩放改变粗细。用 `x2` 从起点推进到终点，避免整条线突然出现：

```js
{
  targets: fitLine,
  x2: [60, 330],
  opacity: [0, 1],
  duration: m.duration,
  easing: m.easing
}
```

同时更新读数：

```js
{
  targets: fitReadout,
  duration: 1,
  begin: function () { fitReadout.set('0.42') }
}
```

### 6.4 相位 3：偏差与初始损失

**语义**：每个点到直线的距离共同构成“代价”。

- caption：`算每个点的偏差，加起来就是损失`
- step：`3 / 4`
- 损失：瞬时更新为 `7.60`
- 播放区间：1,895ms 至 2,355ms

```js
[
  {
    targets: deviationLines,
    opacity: [0, 0.5],
    duration: m.duration,
    easing: m.easing
  },
  {
    targets: lossReadout,
    duration: 1,
    begin: function () { lossReadout.set('7.60') }
  }
]
```

偏差线端点取每个数据点的 `(cx, cy)` 与当前直线的 `(cx, lineCy)`，只画垂直线。若点落在直线下方，仍保持从点到预测位置的垂直方向，不翻转成斜线。

### 6.5 相位 4：第 1 步更新

**语义**：沿损失下降最快方向走第一步。

- caption：`沿损失下降最快方向走第一步`
- step：`4 / 4`
- w：`0 → 1.68`
- loss：`7.60 → 1.79392`
- 拟合度：`0.42 → 0.8474`
- 播放区间：2,735ms 至 3,195ms

```js
[
  {
    targets: [fitLine, fitLineShadow],
    y1: [lineY1(0), lineY1(1.68)],
    y2: [lineY2(0), lineY2(1.68)],
    duration: m.duration,
    easing: m.easing
  },
  {
    targets: [ballHalo, ball],
    cx: [curveX(0), curveX(1.68)],
    cy: [curveY(7.6), curveY(1.79392)],
    duration: m.duration,
    easing: m.easing
  },
  {
    targets: trail0,
    opacity: [0, 0.25],
    r: [1, 4],
    duration: m.duration * 0.55,
    easing: m.easing
  },
  {
    targets: fitReadout,
    duration: 1,
    begin: function () { fitReadout.set('0.85') }
  },
  {
    targets: lossReadout,
    duration: 1,
    begin: function () { lossReadout.set('1.79') }
  }
]
```

### 6.6 相位 5：第 2 步更新

## 11. 可选美学加分项

以下项目按推荐优先级排序。它们全部是低风险、可关闭的加分项。

### A 级：推荐加入

1. **球的双层焦点**：光晕半径 16，主体半径 7，内核半径 2。移动时三层同步，内核使用 `var(--surface)`，不要增加新颜色。
2. **轨迹尾巴递减**：最近一步 opacity 0.25，倒数第二步 0.18，更早步骤 0.12，最多保留 4 个点。
3. **曲线描边入场**：相位 1 结束后，右侧曲线用 `stroke-dashoffset` 从总长度到 0，时长 300ms；若无法可靠测量 path 长度，则静态出现，不要用估算值造成跳动。
4. **读数变更的轻微强调**：数值更新时只做一次 opacity 0.72 → 1，时长 140ms，不改变字号，不做弹跳。
5. **终点确认**：相位 9 的球做一次 `scale [1, 1.08, 1]`，时长 276ms，作为“到达”的视觉句号。

### B 级：视皮肤与性能加入

1. **当前点投影线**：球到 x 轴的短虚线，opacity 0.18；只在球移动期间出现，结束后淡出。
2. **直线右端小帽**：用 5px 短线表达预测方向，不使用三角箭头，避免产生“向量”误解。
3. **局部高亮偏差**：每步只短暂高亮偏差最大的 3 根虚线，opacity 0.72，持续 180ms 后回到 0.5。
4. **面板标题状态点**：标题左侧加 5px 圆点，当前动画面板用 `var(--warn)`，非当前面板用 `var(--accent)`，不增加第三色相。

### C 级：不建议默认开启

- 发光滤镜、粒子爆炸、旋转、镜头缩放、曲线颜色渐变、超过 4 个轨迹尾点、每个散点单独弹跳。

这些效果会把学生的注意力从“参数更新”带到装饰上，并增加 iframe 中的渲染成本。

## 12. 动效降级与可访问性

### 12.1 减少动效模式

当 `Sandbox.motion.duration` 被降为接近 0 时：

- 所有点直接显示为 `r=5, opacity=0.85`。
- 直线直接显示完整终态。
- 偏差线直接显示 `opacity=0.5`。
- 小球和直线直接跳到最终相位坐标。
- 读数仍按相位顺序更新，保证信息顺序不丢。

不要在模板中自行读取系统偏好或新建第二套时长规则，以免和运行时的 reduced-motion 策略冲突。

### 12.2 文字与对比度

- 所有面板标题、坐标文字、读数标签必须是完整字符串。
- 读数数字不使用过细字重。
- 关键状态不能只靠颜色区分：小球位置、直线平移和数字读数都必须同时变化。
- 最优点的虚线标记必须伴随文字“最优 w=3”。
