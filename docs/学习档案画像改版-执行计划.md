### 1.2 ★★ 红线移动记录（本项目安全边界的显式变更，须记入决策）

既有禁做红线（G-M-7 守卫 + 概括 prompt 纪律 + `docs/业务陷阱清单.md`）原文：

> 不要推断学生的**性格、心理状态、家庭情况或智能水平**。

新口径（三处同步改写：`payload.ts` prompt、`onboarding-guards.test.ts` G-M-7、
`docs/业务陷阱清单.md`）：

> 不要推断学生的心理状态、家庭情况或智能水平；性格描述只允许使用给定词表里的词，
> 不使用任何医学、心理学术语。

配套防线（性格维度独有的三道闸，缺一不可）：

1. **枚举词表**：`personality` 的取值域是封闭枚举（默认提案见 §2.2），
   与 `EMOTION_VALUES` 枚举化同一条纪律 —— 自由文本 = 临床词汇侧门
   （「我最近有点抑郁」这类话绝不能原样进库）。
2. **解析侧过滤**：`parseRefreshTags` 对 `personality` 的值做词表校验，不在词表 → 丢。
3. **守卫改写而非删除**：G-M-7 的断言从「prompt 含禁性格字样」改为
   「prompt 含新口径文本」+「心理状态/家庭情况/智能水平三词仍在禁令里」+
   「personality 词表过滤存在」。

⚠️ 红线移动的**不可回退性**提示：一旦画像里出现 AI 推断的性格并展示给学生，
回退时需要处理已有数据。词表枚举化正是为了让回退可执行（一条 UPDATE 清掉越界值）。

## 二、机制设计

### 2.1 预置标签体系：新键 `learner_style`（学习类型）

**词表（默认提案，待用户增删，§六.1）**：

```
天赋型 / 努力型 / 钻研型 / 速通型 / 均衡型
```

**双路打标（裁决 B），分档矩阵天然仲裁**：

```
路 1（observed，权威）：规则投影 —— 后端按学习数据判定
     数据：mastery 全表（attempts/correct/last_seen_at）+ 近 30 天学习记录
     规则（默认口径，实施时用测试钉死）：
       · 总 attempts < 10 → 不投影（样本不足，宁缺毋滥）
       · 天赋型：正确率 ≥ 0.85 且 attempts ≥ 10（首试通过率高）
       · 钻研型：同 kp 平均 attempts ≥ 3（反复打磨同一处）
       · 速通型：平均每 kp attempts ≤ 1.5 且正确率 ≥ 0.7
       · 努力型：attempts ≥ 30 或错题重做占比 ≥ 40%，且正确率 < 0.85
       · 以上都不满足 → 不写（「均衡型」留作词表选项，规则不主动打）
     顺序判定取第一个命中；触发点对齐 `sync_observed_tags` 的既有钩子（判分写入路径）。

路 2（inferred，候补）：持续画像概括 —— LLM 从对话里判断
     概括产出 `learner_style` + source=inferred；prompt 教它「这是你从他学法里看出的倾向」。

仲裁（零新代码）：既有分档矩阵已保证
     observed 不被 inferred 覆盖 → 规则判定的结果 LLM 推不翻；
     数据不足时 inferred 先占位 → 规则一旦能判就升级为 observed。
```

**契约位置**：`learner_style` 进 `LLM_VISIBLE_TAGS`（25 → 27 键）、
进 `INFERRED_ALLOWED_TAG_KEYS`（8 → 10 键）、进 `REFRESH_INFERRED_KEYS`（TS 侧同步）。
`TAG_DIMENSIONS` 挂新维度 13，`TAG_DIMENSION_LABELS[13]` 学生面措辞「类型与性格」。

### 2.2 性格：新键 `personality`（裁决 A）

**词表（默认提案，待用户增删，§六.1）**：中性、口语、无临床色彩——

```
开朗 / 安静 / 好奇 / 沉稳 / 细心 / 勇敢 / 急性子 / 慢性子 / 爱提问 / 爱琢磨
```

**三条写入路径（与既有 source 语义完全对齐）**：

| 路径 | source | 说明 |
|---|---|---|
| 五问自述（Q5「想先告诉我的」里带出） | `declared` | 进 `ONBOARDING_SUMMARY_ALLOWED_KEYS`，学生亲口说的 |
| 对话中表达过（「我是个急性子」） | `observed` | 持续概括按证据性质判（§2.3.1 既有口径） |
| AI 从行为推断 | `inferred` | **本轮放开的路径**：进 `INFERRED_ALLOWED_TAG_KEYS`，值必须命中词表 |

**不属于画像概括的独立防线**：解析侧词表校验（§1.2 防线 2）在后端 `refresh-apply`
与 TS `parseRefreshTags` **两处都有**（判据唯一、落点两处的既有纪律）。

### 2.3 五行结构（名字下方）

```
┌──────────────────────────────┐
│           头像                │
│           名字                │  ← 既有
│        学段 · 来源            │  ← 既有
├──────────────────────────────┤
│ 类型      天赋型 · 爱提问      │  ← 行 1：learner_style + personality（chips 形态）
│ 性格      开朗，爱琢磨          │  ← 行 2：personality（学生面词表中文名）
│ 偏好      讲解风格=生活例子；…  │  ← 行 3：维度 7（怎么讲更好）+ 维度 10（互动偏好）拼装
│ 兴趣      太空；科学实验        │  ← 行 4：interest_topic + scene + task_goal
│ 小结      「你最近在……」       │  ← 行 5：AI 小结（§2.5），80–150 字
├──────────────────────────────┤
│ 最近在学                      │  ← 新区块：mastery 按 last_seen_at 倒序 5 条
│  · 有理数乘法        82%       │     （名字 + 掌握度百分比，复用现有三格行样式）
│  · 一元一次方程       64%      │
├──────────────────────────────┤
│ 建议下一步 …                  │  ← 保留（默认裁决 §六.3）
└──────────────────────────────┘
```

**四条实现纪律**：

1. **行标题全部由后端下发**（新增契约常量 `PORTRAIT_ROW_LABELS`，学生面措辞）——
   渲染层一个字符串字面量都不写，`student-view-discipline` 守卫口径不变。
2. **空态行不渲染**（没有性格数据就不摆一行「性格：无」，后端下发引导文案，
   如「多聊几句我就能更了解你」）。
3. **「我记住了什么」分组列表在档案右栏移除**（默认裁决 §六.2）—— 五行结构就是它的
   重组视图；撤回按钮等维护能力仍在对话页右栏（`ProfileTags` 组件不动，档案右栏不再引用）。
4. **时间线移除**：需求明确「不内置画像变动信息」→ 档案右栏无 timeline；
   对话页右栏的时间线**保留**（`ProfileTags` 默认 `timeline=true` 不变）。

### 2.4 右栏宽度（裁决 C）

```
现值：clamp(232px, 20%, 288px)
新值：clamp(280px, 25%, 348px)
```

下限 280：五行结构里最长的「偏好」行（两个键值对）需要这个宽度才不换行成竖条；
上限 348：1920 窗口下 25% = 480，内容撑不起，维持「上限收口」的既有理由。
`@media (max-width: 1023px)` 堆叠分支的 `max-height: 46vh` 顺带复核（内容变多，
可能需要微调到 50vh 或改为按内容自适应）。

### 2.5 AI 小结（行 5，裁决 D）

**生成时机**：持续画像迭代（`profile-refresh`）落库成功后，fire-and-forget 顺带生成
（复用同一套 `getConfig` 模型配置；不另起触发器）。

**数据输入**：画像标签（白名单投影）+ 最近 5 个知识点 + 掌握度 top4 + 学习类型 + 性格
—— 全部是已脱敏的结构化数据，**不把对话原文再发一遍**（画像概括已经消化过一次）。

**产出纪律**：
- 80–150 字中文一段，团团团对学生说话的口吻（「你最近在学……，更喜欢……」）；
- 禁 PII（`sanitizeStudentText` 不需要 —— 输入本就是标签值，但解析侧仍做长度与
  脏值过滤）；
- 禁负面评价：只能中性或建设性（「你学得不好」不行；「多练几次就会顺」可以）；
- 禁心理诊断词汇（与 personality 词表同一条防线）。

**缓存落点**：主进程本地 JSON（`pi-agent/logs/profile-summary.json`，先例：
`turn-diagnostics.jsonl` 也在这个目录）—— **不进 SQLite**（画像表无正文字段是既有
纪律，自由文本入库 = 侧门）。结构：

```json
{ "studentId": "...", "text": "...", "generatedAt": 1234567890, "tagFingerprint": "..." }
```

`tagFingerprint`（标签集合哈希）用于判断缓存新旧：画像变了 → 下一次 refresh 落库后
自然重生成；打开页面时**只读不生成**（永远不因看一眼档案页而调模型）。

**IPC**：新 invoke 通道 `profile:summary:read`（`channels.ts` 登记 + preload 白名单 +
`check:docs` 通道计数 +1）。

**失败降级**：无缓存 / 读失败 → 显示后端下发的引导文案，不阻塞、不报错红条。

|---|---|
| 契约 | `LEARNING_ACTIVITY_LABELS`（动作中文名，唯一来源）+ `LearningEventEntry` + `LearningEventHistoryOut`（均已登记 `CONTRACT_MODELS`） |
