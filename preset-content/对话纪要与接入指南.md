## 4. 如何接入

### 4.1 产品资源导入（拷进 `server/resources/`）

```text
preset-content/quizbank/*.json          → server/resources/quizbank/
preset-content/code-templates/*.json    → server/resources/code-templates/
preset-content/animations/templates/*.json → server/resources/templates/
```

**不拷**：`by-kp/`、`generator-kit/`、`_meta/`、`templates-premium/`（除非决定用 premium 覆盖同 kp）。

环境变量可**先试跑不拷贝**：

| 变量 | 指向 |
| --- | --- |
| `K12_QUIZ_BANK_DIR` | `preset-content/quizbank` |
| `K12_CODE_TEMPLATES_DIR` | `preset-content/code-templates` |
| `K12_ANIMATION_TEMPLATES` | `preset-content/animations/templates` |

导入后回归：

```bash
cd server
uv run python -m unittest tests.test_quizbank_coverage tests.test_code_templates tests.test_animation_templates -v
```

与 `by-kp` 的接线建议：宿主取动画时按 `kp_id` 读 `by-kp/<kp_id>.json`，用其中的 `steps`/`fallback_text`/`title` **覆写**模板渲染参数（或展开成一 KP 一模板）。加载器只认 `templates/*.json` 的 `kp_ids` 精确命中。

### 4.2 用 AI 再生成 / 自定义（generator-kit）

最小调用块（也可直接抄 `generator-kit/workflow.md`）：

```text
请为 kp_id={{kp_id}}（grade={{primary_low|primary_high|junior|senior}}）
生成 {{quiz|animation|code}} 预置内容。

必读：
- preset-content/generator-kit/grade-style.md
- preset-content/generator-kit/PROMPT-{{kind}}.md
教材正文（唯一事实来源）：
---
{{server/knowledge/<grade-dir>/<kp_id>.md}}
---
只输出符合契约的 JSON。
生成代码模板时必须本地执行 solution，并把 stdout 原样写入 expected_output。
```

| kind | 输出落盘 | 样例 |
| --- | --- | --- |
| quiz | `quizbank/chNN.json` 的 `questions[]` | `examples/quiz-sample.json` |
| code | `code-templates/<kp_id>.json` | `examples/code-sample.json` |
| animation | `animations/templates/<slug>.json`（可选再写 `by-kp/`） | `examples/animation-sample.json` |

硬约束摘要：答案/solution 不外发；pl 禁英文缩写与公式；动画必须 `Sandbox.ready(`+`Sandbox.play(`；文案禁 `——` 与 `**`；`kp_id` 必须已存在于 `server/knowledge/`。

## 5. 分学段结论（对应你的追问）

**有分类生成。** 不是四档共用一份难度数字：

- 题：qid/kp 带 `-pl|-ph|-jr|-sr`，语气与禁用项不同（见 `generator-kit/grade-style.md`）。
- 代码：同学段不同脚手架（例：变量课 pl 数星星、ph 步数、jr 平均分、sr 摄氏转华氏）。
- 动画：模板级 `grade_levels` 四档；**by-kp 级** caption/fallback/步骤按学段重写（「（小学低年级讲法）…」）。

## 6. 遗留与建议

1. **compare 原型**左右短语仍偏概括，产品级文案建议按 `by-kp/*.json` 的 `steps` 人工/二次 AI 精修。  
2. 长概念名在小圆节点会「计算机视…」式截断（有意，完整句在 caption）。  
3. 若决定启用 `templates-premium/` 与 `templates/` 重叠的 22 个 kp：**导入时二选一**，避免同 kp 双模板抢 `pick_template`。  
4. UI 修改（`architecture/修改建议报告.md` 的 P0）尚未动代码，需要另开一轮实现。
