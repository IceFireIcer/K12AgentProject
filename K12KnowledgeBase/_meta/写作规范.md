# 四学段写作规范

本库把每个知识点改写成 **4 个学段版本**：小学低年级（1-2 年级）、小学高年级（3-6 年级）、初中（7-9 年级）、高中（10-12 年级）。

**为什么必须分四段**：同一个概念，四个学段的认知水平完全不同。小学生需要「像什么」，初中生需要「为什么」，高中生需要「怎么运作、边界在哪」。用一套话术打通所有学段，结果就是低年级看不懂、高年级嫌太浅。

---

## 一、四学段对照表

| 维度 | 小学低年级 | 小学高年级 | 初中 | 高中 |
|---|---|---|---|---|
| 字数 | 80-150 字 | 150-250 字 | 250-400 字 | 350-600 字 |
| 句长 | ≤15 字 | ≤25 字 | 可用长句 | 不限 |
| 英语 / 缩写 | **不出现** | 出现必标中文，如「AI（人工智能）」 | 术语 + 英文全称 / 缩写 | 术语、参数、架构名 |
| 比喻 | **必用**，以比喻为主 | 比喻 + 简单因果 | 可讲原理，比喻为辅 | 机制 / 思辨为主 |
| 认知目标 | 只讲「是什么、像什么」 | 「是什么 + 有什么用」 | 「为什么 + 怎么运作」 | 「原理 + 局限 + 跨知识点关联」 |
| 推荐结构 | 2-3 句 + 1 个「想一想」 | 定义 / 特点 / 例子 | 定义 / 原理 / 辨析 / 易错点 | 定义 / 机制 / 架构 / 局限 / 引申 |
| 禁止出现 | 公式、缩写、抽象词 | 复杂公式 | — | — |

### frontmatter 字段说明

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 形如 `章节.小节.序号`，全库唯一 |
| `name` | 是 | 中文知识点名 |
| `en` | 否 | 英文全称；无则写 `null` |
| `chapter` | 是 | 所属章节目录名（与源目录一致） |
| `source` | 是 | 来源 docx 文件名，用于溯源 |
| `stages` | 是 | 固定四个学段，顺序不可变 |
| `difficulty` | 是 | 1-4，与学段一一对应 |
| `tags` | 否 | 用于检索分类 |
| `related` | 否 | 关联知识点 id，双向互链 |

## 四、格式硬要求

1. **四个学段标题必须是 `## 小学低年级` / `## 小学高年级` / `## 初中` / `## 高中`**，顺序固定、不可缺、不可重复——自动化脚本依赖这四个锚点切分。
2. **正文不得残留 U+200C（零宽非连接符）**。源 docx 全库有 62 处，改写时必须清除。
3. 源文档里形如 `##`、`**加粗**`、`- 列表` 的**字面量**只是普通文本（不会被渲染），本库统一改写为真正的 Markdown 语法。
4. **不要把源文档的表格直接粘成 Markdown 表格塞进学段小节**——按学段拆成叙述或对照列表；需要保留总览表的，放该章 `README.md`。
5. 术语全库统一：人工智能（AI）、机器学习（ML）、深度学习（DL）、大语言模型（LLM）、检索增强生成（RAG）、智能体（Agent）。首次出现标全称，之后用简称。
6. **高中版是全库的准确性锚点**：低学段可以简化，但不得与高中版事实冲突。

## 五、内容红线（第七章及所有学段）

1. **不直接给出完整标准答案**——教育 AI 只给思路、分步引导，学生要自己完成思考（来源：7.3）。
2. **不收集、不外传学生敏感个人信息**——姓名、身份证、家庭住址、答题记录等（来源：7.2）。
3. **提示核验**——AI 会幻觉，重要内容必须对照课本与权威资料（来源：6.1、7.1）。
4. **分层适配**——对低年级、基础薄弱、有障碍的学生调整难度与呈现形式（字幕、朗读等）（来源：6.5、7.4）。
5. **6.5「教学短板」是调研发现的痛点、5.1 教育领域是课题重点研究方向**，改写时不可弱化或省略。

## 六、自检脚本校验项

- 每份 `.md` 含且**按序**含四个 `## ` 学段标题，无缺失 / 重复
- frontmatter 字段齐全，`id` 全局唯一，`source` 指向的 docx 真实存在
- 各学段字数落在第一节区间内
- 小学低年级段**不出现英文缩写、不出现公式**
- 全文无残留 U+200C
- 第七章四份均含「不直接给答案 / 隐私 / 核验」对应表述
