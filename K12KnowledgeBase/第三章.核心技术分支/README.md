# 第三章.核心技术分支

**章节导语**

人工智能包含多个核心技术分支，不同分支负责不同的能力。

如果把人工智能比作一座工厂，那么**机器学习（ML）与深度学习（DL）是底层基础**，负责提供「学习」和「表示」的能力；而**自然语言处理（NLP）、计算机视觉（CV）、语音技术**是面向实际业务的应用技术，负责处理文字、图像和声音。

这些分支不是彼此孤立的：教育 AI 智能体就是多项技术组合实现的结果——它要用语音技术听懂学生的提问，用自然语言处理理解题意，用计算机视觉批改手写作业，而支撑这一切的，是底层的深度学习与机器学习。各分支的包含关系可参见 1.3.1。

**技术分支总览表**

| 技术分支 | 核心说明 | 教育场景例子 |
|---|---|---|
| 机器学习（ML） | AI 基础学习范式，分为监督、无监督、强化学习 | 考题识别、学生用户行为分析 |
| 深度学习（DL） | 机器学习的子类，依靠神经网络；Transformer 是大模型底层 | 大语言模型底层技术基础 |
| 自然语言处理（NLP） | 处理人类文字语言，大语言模型属于该分支 | 答疑讲解、作文生成、知识点总结 |
| 计算机视觉（CV） | 机器看懂图片、视频 | 拍照搜题、手写作业识别批改 |
| 语音技术 | 语音和文字互相转换 | AI 语音朗读、语音提问答题 |

**分支之间的关系**

- 人工智能包含机器学习，机器学习包含深度学习——这是一条由大到小的包含链（3.1.1 → 3.2.1）。
- 三支学习方法（监督、无监督、强化）是机器学习内部并列的三条路径，区别在于学习信号是「标签」「无标签」还是「奖励」。
- 深度学习的最小单元是人工神经元（3.2.2），神经元连成神经网络（3.2.3），多层网络之上发展出 Transformer（3.2.4）与 Token（3.2.5）机制。
- 自然语言处理、计算机视觉、语音技术是面向业务的应用分支，都建立在深度学习之上，各自处理一类数据模态。

**本章内容的四学段呈现**

同一批知识点，在四个学段用不同的讲法。下面说明各学段这一章怎么读。

## 小学低年级

这一章在这个学段只讲「它像什么、它是干什么的」。

认识机器学习，就像看小朋友从很多图片里学会认猫。认识深度学习，就像看很多人排成一队，每人只看一点点，合起来就把难事做完了。

这里不出现英文缩写，也没有公式。读一读比一比，能说出机器是怎么学会本领的，就足够了。

## 小学高年级

这个学段开始给出准确的说法：机器学习是让机器从大量数据中自己找规律；它分三类，监督学习用带答案的例子来教，无监督学习只有数据没有答案，强化学习靠一次次尝试和奖励来改进。

深度学习是机器学习的一个子类，用多层网络自己提取特征。它有几个基本要点：人工神经元是最小单位，神经元连起来构成神经网络，处理文字还要先切成 Token。

每个知识点都配了生活和教育场景的例子，比如用标注好的题目图片训练模型实现拍照识别。

## 初中

初中阶段要讲清「为什么」和「怎么运作」，并给出辨析。

三支学习方法必须横向对照：它们的根本区别在于学习信号不同——监督学习有标签，无监督学习没有标签，强化学习靠与环境交互得到的奖励。这个对照表比单独背诵定义有用得多。

深度学习部分要理解「自动提取特征」的含义，以及人工智能、机器学习、深度学习三者的包含关系。人工神经元做的是加权求和再经过激活函数；神经网络先做前向传播，再用反向传播按误差调整权重。

易错点也要交代清楚：机器学到的是统计规律而不是因果，数据有偏则结论有偏；聚类结果没有唯一答案，需要人来解释；奖励设计不当会让智能体钻空子。

## 高中

高中阶段是全库的准确性锚点，用术语、公式与机制来讲，并指出边界。

机器学习的形式化表述是：在假设空间中搜索使经验风险最小的假设，同时控制泛化误差以防过拟合。神经网络的基本式是层层复合的仿射变换与非线性激活，训练由损失函数定义目标，反向传播按链式法则求梯度，梯度下降类优化器更新参数，这就是完整的训练闭环。

三支学习方法的对照也上升到范式层面：监督学习从标注数据学映射，无监督学习从数据分布学结构与表示，强化学习在马尔可夫决策过程下最大化期望折扣回报，因此样本效率低、训练不稳定。要能辨析三者并非互斥，自监督学习就是用数据自身构造标签的组合形式。

局限也必须讲到：深度模型的输出只能作为教学辅助，涉及重要内容时须对照课本与权威资料核验（参见 6.1、7.1）；模型还可能继承训练数据的偏差（参见 7.4）。此外，Transformer 的自注意力机制与 Token 切分是理解大语言模型行为的入口，建议与第四章 4.1.1 对照阅读。
