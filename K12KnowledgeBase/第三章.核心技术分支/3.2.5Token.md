# Token

> **一句话核心**：模型处理文字时的最小单位，把一段话切成一个个小片段再交给它读写。

## 小学低年级

机器读文章，不是像我们一样一个字一个字看的。

它会把句子切成很多小碎块，一块一块地看。

这些小碎块就是它的「字」。

就像拼积木，先有很多小零件，才能搭出一整座房子。

想一想：如果把「今天天气很好」切成小块，你会怎么切？

## 小学高年级

Token（词元）是大语言模型处理文字时的最小单位。

模型没法直接看懂一句话，它要先做**切分**：把文字切成一个个小片段，每个片段就是一个词元。这个词元可能是一个字、一个词，也可能是几个字拼起来的一段。

切好之后，每个词元都会被换成一个编号，模型其实就是在一串编号上做计算。它也是这样「写」字的：一个一个词元地往外蹦。

这个词元还有一个用处——**数长度**。模型一次能处理的词元数量是有限的，所以人们常用它来衡量一段文字有多长。通常一个汉字大约算一个词元。

划重点：词元是模型读写文字的基本颗粒。

## 初中

词元（Token）是大语言模型处理文本的最小单位，模型不能直接处理文字，只能处理编号，因此文本必须先被切分成词元再映射成数字。

这个过程叫**分词**。常见的做法是子词切分：不按字也不按词硬切，而是把常见的字词整块保留，把生僻的词拆成更小的片段。这样既能控制词表规模，又能表示没见过的词。

切分后，每个词元对应词表中的一个编号，模型看到的其实是一串整数；输出时再反过来，把预测出的编号还原成文字。

为什么重要？模型一次能处理的词元数量有上限，这个上限叫**上下文窗口**，超出部分会被截掉或遗忘。所以提问时如果材料太长，模型可能「看不到」前面的内容。

易错点：词元不等于字，也不等于词；同一个句子，不同的模型切出来的词元可能不一样。

## 高中

Token（词元）是语言模型的基本离散单元。文本先经分词器切分为词元序列，再通过词表映射为整数 id 输入网络；生成时模型对词表做概率分布预测，逐词元采样并解码回文本。因此模型的输入输出长度、推理成本与上下文窗口（context window）均以词元计量。

现代大模型普遍采用**子词切分**，如字节对编码（BPE）：从字符出发反复合并高频相邻对，使常见词保持为单个词元、生僻词退化为若干子词。其权衡在于词表规模与序列长度的平衡——词表越大，序列越短但参数占用越高。中文因无空格分隔，通常按字或常见词组切分，一个汉字常接近一个词元。

**与上下文窗口的关系**：自注意力对序列长度的计算量随词元数呈二次增长（参见 3.2.4），上下文窗口因此存在上限；超出窗口的文本需截断、摘要或借助检索增强生成（4.2.1）外挂知识。这也解释了为何长文档问答需要分段处理，以及模型在长对话中会「忘记」早期内容（参见 4.3.1、6.4）。

辨析：词元是**模型视角的单位**，与人类直觉的字、词不完全对应，同一文本在不同分词器下词元数不同，因此不能简单用词元数当作字数。
