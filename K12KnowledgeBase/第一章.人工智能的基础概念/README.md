# 第一章.人工智能的基础概念

> **一句话核心**：人工智能是让机器模拟、延伸和扩展人类智能的技术科学；它包含机器学习，机器学习包含深度学习，深度学习里有生成式大模型。

### 章节导语

这一章要解决三个最基本的问题：**人工智能是什么**、**它可以分成哪几类**、**它和机器学习、深度学习是什么关系**。

回答第一个问题，关键是抓住定义里的「模拟、延伸、扩展」三个词——它们不是并列的，而是由低到高的三层价值。回答第二个问题，要分清弱人工智能和强人工智能：前者只会一件事，后者什么都能学，而后者目前还没有实现。回答第三个问题，需要建立一个「包含关系」的印象：人工智能最大，里面套着机器学习，再里面套着深度学习，最里面才是生成式大模型。

需要提醒的是，人工智能已经有七十多年历史，并不都是高科技，你家小区门口的自动抬杆、电梯超重报警，本质上都用到了它。把这一章的概念理清，后面几章才好展开。

## 小学低年级

这一章告诉你：机器是怎么变聪明的。

最早，机器只会照着我们写的步骤做事。后来，人教它看很多很多例子，它自己就学会了一些本领，比如认脸、听懂话。

要记住两件事。第一件，机器里最厉害的那种，会自己写故事、画画，那是「会创造的机器」。第二件，现在所有的机器都只会做一件事，没有一台是什么都会的。

读的时候想一想：你见过的机器，都会做什么呢？

## 小学高年级

本章是整个人工智能知识的第一站，共三件事：什么是人工智能、它分成哪两类、它和机器学习是什么关系。

读定义时，抓住「模拟、延伸、扩展」三个词：先学着做人会做的事，再做人做不到的事，最后做出人没想到的事。读分类时，分清「只会一件事」和「什么都会」这两种机器——前者就是我们现在用的全部机器，后者还只在电影里。读层级关系时，记住水果、苹果、红富士的比方，一层套一层，就不会把几个概念弄混。

建议按 1.1、1.2、1.3 的顺序读，读完用自己的话把三个问题各回答一遍。

## 初中

本章建立人工智能领域的基本概念框架，包含定义、分类与层级三个部分。

定义部分要把握「模拟、延伸、扩展」的递进关系，并澄清两个常见误解：AI 不等于机器人，AI 也不等于有意识。分类部分以「通用性与自主性」为判据，区分弱人工智能与强人工智能；要特别注意，包括大语言模型在内的所有已部署系统都属弱人工智能，「会聊天」不等于「有自我意识」。层级部分给出四层包含结构：人工智能 ⊃ 机器学习 ⊃ 深度学习 ⊃ 生成式大模型，注意这是包含关系而非并列关系，且内层之间还穿插着「判别式 / 生成式」这一正交维度。

阅读时建议关注每节的「辨析」与「易错点」，并试着把「水果—苹果—红富士」这一类比套用到其他概念层级上。

## 高中

本章是后续所有章节的概念地基，建议以「定义—分类—架构」三层递进来掌握。

定义层面，核心是把「智能」理解为**功能描述**而非意识判断，这是理解整个领域的前提；「模拟、延伸、扩展」三层价值则提供了一个评价应用技术含量的分析框架——复刻人类基准、超越生理极限、产生涌现式发现，三者的技术难度与哲学意味依次递增。分类层面，弱人工智能与强人工智能的分界不在性能量级而在**通用性与自主性**；由此可推导出，当前以 Transformer 为骨干的模型虽在文本域表现通用，其机制仍是单一模态的自回归生成，仍属 ANI 范畴。架构层面，四层包含关系体现了「外延递减、内涵递增」的概念组织原则，而生成式与判别式的划分则是与之正交的另一个维度，不可混淆。

思辨层面，本章埋下了两条贯穿全库的线索：其一，AGI 的实现路径之争（规模化、架构、具身三种假说）实质上是对「智能」定义本身的争论；其二，生成式模型的「创造」究竟是真正的创造，还是高维分布上的插值与重组——这一问题将在 6.3 理解局限处再次出现，并直接关联 7.1 的核验责任。建议在阅读后续章节时，持续用本章的层级框架为每个新概念定位。
