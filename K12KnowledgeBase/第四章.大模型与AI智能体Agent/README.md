# 第四章 大模型与AI智能体Agent

人工智能智能体（Agent），是基于大语言模型构建，具备记忆、任务规划、调用工具、自我反思能力的智能系统。它不只是简单问答，而是能够自主完成一整套任务流程，是教育智能体的底层技术基础。

简单理解：大语言模型是大脑，再搭配知识库、记忆、规划、工具等模块，组合成可以自主做事的 AI 智能体。

本章按「大脑 → 外挂知识库 → 记忆 → 五大核心模块 → 提示词」的顺序展开，逐一说明这些组件各自解决什么问题、为什么缺一不可。

### 整体技术组件总览表

| 技术组件 | 核心作用 | 通俗解释 | 教育场景实例 |
|---|---|---|---|
| 大语言模型 LLM | 智能体的大脑，负责推理、理解、生成文本 | 负责思考、理解问题、输出文字回答 | 分析题目、讲解知识点、组织语言 |
| RAG 检索增强生成（外挂知识库） | 接入外部资料，补充模型原生知识；适用教材知识点、题库、学习资料 | 给 AI 额外装上课本、题库资料，弥补模型幻觉、知识截止缺陷 | 导入教材、习题，保证答案准确贴合课本 |
| Memory 记忆模块 | 分为短期记忆、长期记忆 | 记住对话过程与学生个人学习情况 | 短期记住本次聊天上下文；长期记住学生薄弱知识点、学习历史 |
| Agent 五大核心模块 | 感知—规划—工具调用—执行—反思 | 一套完整自主工作流程 | 接收提问→拆解难题→查题库→输出讲解→自查纠错 |
| Prompt 提示词 | 设定 AI 角色、输出格式、语言风格；实现分层讲解 | 给 AI 下达角色指令，控制说话风格难度 | 设置为小学老师／高中辅导老师，调整讲解难度 |

## 小学低年级

这一章讲一个很会做事的机器。

它有一个会读会写的大脑，还外挂了一本课本。它记得你刚才说的话，也记得你哪里学得不好。

它还会自己想办法、查资料、做完再检查一遍。

你想让它讲得简单一点，就好好告诉它。

## 小学高年级

本章介绍会自己做事的机器——智能体（英文简称 Agent）。

它的核心是会读会写的大脑，负责理解和回答；还外挂了知识库，回答前先查教材和习题，让答案更贴合课本；它有记忆，能记住聊天内容和学生的薄弱知识点；它有五个核心模块，能从听懂问题一直做到自查纠错；最后靠提示词设定角色和难度，实现分层讲解。

这些部分组合起来，才算是一个能独立完成任务的智能体。

划重点：模块配合得越好，机器办的事就越靠谱；但它给出的内容，仍然需要人来核验。

## 初中

本章围绕大语言模型（LLM）与智能体（Agent）的组件结构展开。大语言模型是中枢，承担意图理解、推理与文本生成，但它的知识来自训练语料，存在幻觉与知识截止的固有缺陷。

补齐缺陷的路径有三条：检索增强生成（RAG）接入教材、题库等外部资料，让回答有据可依（4.2.1）；记忆模块分为短期与长期，前者维护会话上下文，后者持久保存学习数据、支撑个性化辅导（4.3）；工具调用让模型借助计算器、检索等外部能力，避免仅凭内部记忆作答（4.4.3）。

在此之上，感知、规划、工具调用、执行、反思五个模块串成完整工作流，使系统能自主完成任务；提示词则通过角色设定与格式约束，控制输出的难度与风格（4.5.1），是分层讲解的实用手段。

本章的理解主线是：单个模型能力有限，智能体的价值在于用工程结构把多种模块组合起来，各自弥补对方的短板。但也应看到，模块化并不能消除幻觉，重要内容仍须核验（参见 6.1）。

## 高中

本章讨论从「语言模型」到「智能体」的架构跃迁。大语言模型以 Transformer 为骨干，在海量语料上以自监督方式预训练，推理时自回归地逐词生成，因而具备通用语言能力却缺乏外部知识更新、持久记忆与执行能力——这构成了智能体架构的出发点。

围绕这一中枢，各组件分工明确：RAG（4.2.1）通过切分、嵌入、向量检索把外部语料注入上下文，将输出锚定到可溯源证据，缓解幻觉与知识截止；记忆模块采用分层设计，短期记忆以完整上下文形式维护会话状态，长期记忆以结构化与向量存储跨会话持久化，并通过检索回注；五大核心模块（感知—规划—工具调用—执行—反思）构成自主任务循环，其中反思机制形成自我校验闭环；提示词（4.5.1）则在推理阶段施加条件约束，零样本、少样本与思维链等范式可在不更新参数的前提下引导模型能力。

需要强调的是，这一架构在工程上高度有效，却并不改变模型的本质边界：语言合理性不等于事实正确性，模块组合只能降低而非消除错误。同时，长期记忆与学习数据的引入把技术问题延伸为伦理问题——数据最小必要、知情同意、脱敏存储与公平使用（7.2、7.4）必须内建于设计之中。

思辨：智能体的能力来自「模型＋外部结构」的协同，这提示我们评估 AI 系统时应看整体架构而非单一模型；而教育场景的特殊性在于，它的输出直接作用于学生认知，因而对可解释性与可核验性的要求远高于一般应用。
