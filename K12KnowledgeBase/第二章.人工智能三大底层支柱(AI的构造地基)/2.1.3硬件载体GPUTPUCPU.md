# 硬件载体：GPU / CPU / TPU

> **一句话核心**：算力要有实体来承担——图形处理器擅长同时做大量重复计算，通用处理器擅长处理各种杂事，专用芯片则为机器学习量身定制。

## 小学低年级

机器动脑筋，要靠一块小小的零件。

这块零件像一个小工厂。它里面有很多很多小工人，一起干活，算得又快又多。

不同的零件本领不一样：有的什么活都能干一点，有的专门干一种活，干得特别快。

想一想：你觉得是很多小工人一起快，还是一个大力士自己干更快？

## 小学高年级

人工智能的算力，要靠具体的硬件零件来实现，常见的有三种。

**图形处理器**：里面有很多小计算单元，原本是给游戏画面用的，后来大家发现它特别适合让人工智能同时做大量简单计算，于是成了训练大模型最主要的硬件。

**通用处理器**：本领全面，什么任务都能处理，但一次能同时干的事比较少，更像电脑里的总管。

**专用芯片**：专门为人工智能设计，干特定任务时又快又省电。

划重点：它们各有各的用处，通常会配合使用，不是谁完全替代谁。

## 初中

硬件载体是算力的物理承担者，主流有三类：GPU（图形处理器，Graphics Processing Unit）、CPU（中央处理器，Central Processing Unit）和 TPU（张量处理器，Tensor Processing Unit）。

三者的设计思路不同。**CPU** 核心少但每个核心很强，擅长逻辑判断、分支跳转等复杂串行任务，是计算机的总调度者。**GPU** 拥有成百上千个较简单的核心，擅长并行处理大量同类运算，而人工智能的核心计算正是大规模矩阵乘法，因此 GPU 成为训练大模型最主要的硬件。**TPU** 是专为机器学习设计的定制芯片，在特定张量运算上能效更高。

辨析：CPU 与 GPU 不是替代关系，而是分工关系——CPU 负责调度与串行逻辑，GPU 负责并行计算。教育场景中，学校用图形处理器集群训练教育智能体，用通用处理器处理系统调度与数据管理，二者配合完成从训练到在线答疑的全流程。

## 高中

GPU、CPU、TPU 代表三种计算架构取向，差异源于对「并行度」与「通用性」的不同取舍。

**CPU** 面向通用串行计算：核心数少（数十核）、单核性能强，配有复杂的控制逻辑与多级缓存，擅长分支密集、依赖链长的任务，在系统中承担调度与操作系统级工作。**GPU** 面向数据并行：以数千个流处理器（SM）与单指令多线程（SIMT）模型，把大量同构运算分摊到众多线程，非常适合矩阵乘与卷积等深度学习的核心算子；配合高带宽显存（HBM）缓解访存瓶颈，因而成为大模型训练的主力。**TPU** 采用脉动阵列（systolic array）等专用数据流架构，为张量运算硬连线优化，在特定负载下能效与吞吐优于通用 GPU，但灵活性较低、依赖特定软件栈。

关键辨析：评价硬件不能只看峰值算力。实际性能还取决于显存容量与带宽、片间互联、精度支持（FP16/BF16/INT8）以及软件生态。训练常受限于显存与通信，推理则更受带宽与延迟约束。

局限与思辨：专用芯片带来高性能的同时也带来锁定风险；算力集中还涉及成本与能耗。硬件只是载体，其价值最终要由数据（2.2.1）和算法（2.3.1）来兑现。

教育场景：教育智能体的训练依托 GPU/TPU 集群，线上答疑的推理则可用量化后的模型部署在中低端硬件上，从而在成本与体验之间取得平衡。
