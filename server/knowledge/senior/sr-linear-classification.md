## 一、从回归到分类：先算分，再压成概率

线性回归输出一个数值。如果把任务换成分类，比如「根据两门课的作业完成度判断这位同学是否需要补课」，输出应该只有两个答案：需要／不需要。

做法很直接：**先照旧算一个线性得分**。

**得分 = 权重₁ × 完成度₁ + 权重₂ × 完成度₂ + 偏置**

得分可以是任意实数，正数表示「偏向需要补课」，负数表示「偏向不需要」，但它的数值本身不好解释——得分 3.7 到底算「有点需要」还是「非常需要」？

所以第二步是**把得分压到 0 到 1 之间**，让它读起来像一个概率。最常用的压缩函数叫 **Sigmoid**：

**概率 = 1 / (1 + e^(−得分))**

它有几个很好的性质。得分等于 0 时概率正好是 0.5，表示完全拿不准；得分越大越接近 1，得分越负越接近 0；而且不管得分多大，输出永远落在 0 和 1 之间，不会被解释成「120% 需要补课」这种荒谬的值。这条链路（线性得分 → Sigmoid → 概率）就是**逻辑回归**。

名字里带「回归」，它做的却是分类，这是一个历史遗留的命名。记住它实际的形态就够了。

## 二、怎么衡量「概率算得准不准」

现在模型输出的是概率，不是类别，所以损失函数也要换。回归里用的均方误差在这里不合适：它惩罚得太轻，而且当模型错得很离谱时，梯度会变得很小，参数几乎不动。

分类任务常用的是**交叉熵**。它的写法不长，但直觉很好抓：

- 真实答案是 1（需要补课），模型给出 0.9 → 误差很小；
- 真实答案是 1，模型给出 0.1 → 误差很大，而且**给得越接近 0，误差增长得越快**（因为取了对数）；
- 真实答案是 0 的情况对称处理。

这个「错得越离谱，罚得越狠，而且梯度仍然够大」的性质，正是分类任务需要的。它和均方误差的关系可以用一句话概括：**损失函数的选择要匹配输出的形态。** 输出是数值、误差大致对称时用均方误差；输出是概率时用交叉熵。

有了损失，训练流程和前面完全一样：初始化权重，算预测概率，算损失，求梯度，沿反方向更新，重复很多轮。**线性模型 + Sigmoid + 交叉熵**这套组合，是理解一切分类网络的起点——后面无论加多少层，最后这一段的形态几乎都不变。

## 三、边界与局限

逻辑回归学到的东西是一个**线性决策边界**：在高维空间里，它用一张「超平面」把两类样本分开。二维时那就是一条直线，三维时是一个平面。

这带来两个直接后果。

**好处是可解释。** 权重是能读的：某门课完成度的权重是 2.1，就表示这个量每提高一个单位，属于「需要补课」的那一侧的可能性会明显上升。在需要向人解释判断依据的场合（教育、医疗、金融），这种可读性非常有价值。

**局限是表达能力有限。** 如果两类样本的分布真的是一圈套一圈（比如「完成度都高但某一门特别低」才算异常），一条直线无论怎么摆都分不开。这时候有两条路：一是**构造新特征**——比如把「两门完成度之差」作为一个新特征加进去，让分界线在新的空间里变得可分；二是**换一个非线性模型**——下一节要讲的神经网络，就是靠堆叠层来自动学出弯曲的边界。

想一想：如果只用「两门课完成度是否都超过 60%」这一条规则来分类，它对应于权重取什么值的线性模型？如果真实规律要求「两门都过」，这个线性模型够用吗？
