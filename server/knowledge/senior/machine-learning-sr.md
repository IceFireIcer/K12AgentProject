## 机制、边界与关联

机器学习（Machine Learning，ML）研究如何让计算机从数据中自动获得规律，并据此对未知样本作出预测，是人工智能的核心方法论。

形式化地，给定样本空间与候选的假设空间，学习算法在训练数据上搜索使经验风险最小的假设 $f$，同时通过正则化、早停等手段控制泛化误差，避免过拟合。完整流程通常包括：数据准备与划分、模型选择、定义损失函数、参数优化（如梯度下降）与评估。

按监督信号可分为三类，对照维度是「数据是否有标签 / 反馈形式 / 学习目标」：**监督学习**（3.1.2）从标注数据学映射，目标是预测；**无监督学习**（3.1.3）从无标注数据发现结构，目标是发现；**强化学习**（3.1.4）从奖励信号学策略，目标是决策。

教育场景：拍照识别题目属于监督学习中的分类任务；分析学生做题行为、聚类共性薄弱点属于无监督学习。

局限：依赖数据规模与质量，学到的多为统计相关而非因果。延伸见 1.3.1 包含层级关系与 3.2.1 深度学习。
