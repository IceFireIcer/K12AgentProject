## 机制、边界与关联

执行模块（Action / Execution）是智能体的动作执行与内容生成层，即所谓「执行引擎」，负责将规划结果与工具返回物化为最终交付物。

机制上，它按规划确定的结构化步骤逐项生成内容：调用生成能力产出讲解文本，按模板组织练习题与答案要点，调用绘图或结构化输出能力生成思维导图。执行并非被动渲染——它需要维护上下文一致性（前后步骤不矛盾）、控制输出格式（可解析的 Markdown 或 JSON），并在工具返回为空或超时时执行降级策略。

在闭环中，执行承接工具调用（4.4.3）的输出，其产物被反思模块（4.4.5）审查；反思若判定不合格，执行模块会依据反馈重新生成，构成「生成—校验—修正」的迭代。教育应用如自动生成讲义与思维导图（5.1.5）正是本模块的典型落地。

局限与思辨：输出流畅不等于正确，语言模型可能生成自洽但错误的内容，故必须配合来源标注与核验提示（6.1、7.1）；同时不得给出可直接抄袭的完整标准答案，应保留学生的思考空间（7.3），并按学段与个体差异调整难度与呈现形式（7.4）。
