## 是什么、有什么用

工具调用模块是智能体的第三环，负责在需要的时候主动使用外部工具。

它能做的事有：检索知识库里的课本内容、调取题库中的练习题、查询资料，还可以调用计算器等程序。

比如规划模块发现「要讲三角形面积」，它就先去知识库找出教材上的说法，再到题库里挑几道难度合适的题。

在整个流程中，它排在规划之后、执行之前，是把「计划」变成「有依据的材料」的一步。

划重点：大模型自己可能会记错，查过资料再回答会可靠得多。
