## 用生活打比方

有时候你记不住一个字怎么写，就会去查字典。

智能体也一样，遇到不会的内容，它不会瞎猜，而是去「翻书」「查资料」。

它会去查课本里的知识，还会去题库里找合适的练习题。

借来这些工具帮忙，它回答得才更准。

想一想：你写作业时，会用到哪些帮你查东西的工具？
