## 原理与辨析

工具调用模块（Tool Use）让智能体能够访问自身参数之外的信息与能力，是弥补大模型幻觉与知识截止的通道。

它依托检索增强生成（RAG，参见 4.2.1）向外挂知识库取回相关段落，也能调取题库、调用计算器等确定性程序。典型流程是：规划模块给出待查问题，本模块生成检索请求、取回结果并筛选出最相关的片段，再交给执行模块组织成回答。

在五模块流程中，它位于规划与执行之间，扮演「找材料」的角色。有了它，答案就不再只依赖模型记忆。

辨析：工具调用与训练不同——调用工具是在使用时临时获取信息，不会改变模型本身的参数。

易错点：检索不到合适内容时，智能体应当承认并提示核验，不能凭空编造（参见 6.1）。
