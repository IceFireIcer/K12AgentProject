## 原理与辨析

执行模块（Action / Execution）负责生成并交付最终产出，是五模块流程中唯一直接面向学生的环节。

它把规划的步骤顺序、工具调用取回的材料整合起来，组织成连贯的输出：先复述题意，再分步讲解，然后给出配套练习或思维导图。输出的格式、篇幅与难度由提示词设定（参见 4.5.1），面向不同学段的学生要调整表达方式（参见 7.4）。

在流程中，它是承接工具调用的下游、反思模块的上游：反思要检查的正是这里生成的内容。

辨析：执行不等于「给出答案」。在教育场景里，它应当给出思路和引导，把最后一步留给学生自己完成（参见 7.3）。

易错点：如果检索材料质量差，执行模块会把它照搬出来，所以输出前仍需核对来源。
