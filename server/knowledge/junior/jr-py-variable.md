## 一、变量是给数据起的名字

写程序处理数据时，第一个要建立的直觉是：程序里的每个数、每段文字，都需要一个名字，否则你没法在下一次用到它。

这个名字就是**变量**。

```python
age = 13
name = "小明"
height = 1.62
```

第一行读作：把 13 这个值放到名为 `age` 的名字下面。这个动作叫**赋值**，等号就是「放进去」的意思，不是数学里的「相等」。所以 `age = age + 1` 在程序里完全合法，它表示「把 age 原来的值取出来，加 1，再放回 age」，执行一次 age 就多了 1。

为什么要给数据起名字？因为程序要处理的是「一批数据反复计算」的过程。假如要算全班 40 位同学的平均分，你不可能为每个分数写一个临时结果；你会用 `total` 存累计总和，用 `count` 存人数，每读一个分数就更新一次。名字让计算过程可读、可改、可检查——这一点比语法重要得多。

关于命名有三条实用建议。第一，**名字要说明含义**：`total` 比 `t` 好，`student_count` 比 `sc` 好。第二，只能用字母、数字、下划线，且不能用数字开头；变量名区分大小写，`score` 和 `Score` 是两个不同的名字。第三，避开 Python 自己已经占用的名字（例如 `print`、`list`、`sum`），否则你写的名字会把原来的功能盖掉，报错时非常难查。

## 二、类型不同，能做的事不同

同一个变量，装的东西可以不一样。常见的几种基本类型是：

- **整数**（`int`）：`count = 40`，用来计数；
- **小数**（`float`）：`average = 87.35`，用来表示测量值和计算结果；
- **字符串**（`str`）：`name = "小明"`，用来放文字，必须用引号包起来；
- **布尔值**（`bool`）：`passed = True`，只有真和假两种取值，专门用于判断。

类型决定了这个变量能参加什么运算。

```python
print(3 + 4)          # 7，两个整数相加
print("3" + "4")      # 34，两段文字拼在一起，不是 7
print("3" * 3)        # 333，字符串重复三次
```

第三行很能说明问题：同一个符号 `*`，作用在整数上是乘法，作用在字符串上是重复。程序不是在做数学，它是在按类型执行规则。所以拿到的数据是文字还是数字，必须心里有数。

数据分析里最常踩的坑就是**类型不对**。比如从表格里读进来的一列成绩，可能带着空格，或者被当成了字符串 `"87"`，这时 `"87" + 5` 会直接报错。正确的做法是先用 `int()` 或 `float()` 把它转成数字：`score = float("87")`，再参与计算。

再进一步，还有能装很多值的类型，比如列表 `scores = [88, 92, 75]`，它让「一批数据」有了一个名字。等你学会用变量配合列表，就能写出真正的数据处理程序：一行一行地读、一个一个地算，最后输出结论。
